## مبانی علمی و چرایی

در Python متغیرها به اشیا اشاره می‌کنند؛ نوع به مقدار متعلق است. dataclass به‌طور خودکار سازنده تولید می‌کند ولی type hint به خودی خود ورودی را بررسی نمی‌کند. برای مرز ورودی باید bool را از عدد جدا تشخیص داد، چون bool زیرکلاس int است.

**کار ویژه این مأموریت:** دو بار اجرا را اندازه بگیر و پیش از ادعای سرعت، نمونه قابل بازتولید با اندازه داده و سخت‌افزار یکسان ارائه کن.

قبل از بهینه‌سازی baseline بگیر؛ دست‌کم چند بار تکرار کن و میانه/بازه را بسنج. سرعت بدون عدد اندازه‌گیری‌شده، فقط فرضیه است.
