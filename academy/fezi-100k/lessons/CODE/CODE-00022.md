هدف: یادگیری و ارزیابی «پیاده‌سازی پایه» برای موضوع «اصول زبان / متغیر و نوع داده» در سناریوی «ربات تلگرام دارای تست». پیش‌نیازها: فهم متغیر، نوع داده، JSON و ساختار فایل. منابع انسانی برای بازبینی نهایی و کلیدهای محیط عملیاتی لازم‌اند؛ این فایل هیچ‌کدام را همراه ندارد.

## مبانی علمی و چرایی

رویداد تلگرام به صورت JSON می‌رسد؛ update_id و chat.id عدد صحیح‌اند، متن ممکن است وجود نداشته باشد. تابع پردازش باید داده ناشناخته را رد کند، پاسخ متناسب با زبان بسازد و offset را فقط با شناسه عددی به‌روزرسانی کند. ارسال واقعی sendMessage نیاز به توکن و شبکه دارد.

**کار ویژه این مأموریت:** یک نمونه حداقلی راه‌اندازی کن که ورودی معتبر را پردازش، خروجی JSON را صادر و خطاهای ورودی را رد کند.

برای حداقل نمونه عملی، ورودی ثابت و خروجی قابل پیش‌بینی بساز. نصب وابستگی بیرونی لازم نیست. هر اجرای موفق نمونه را به کل محصول تعمیم نده.
