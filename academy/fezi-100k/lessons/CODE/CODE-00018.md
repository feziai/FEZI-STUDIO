## مبانی علمی و چرایی

در Node.js یک مقدار از JSON ممکن است string، number، boolean، array یا object باشد؛ typeof برای آرایه و null کافی نیست. ورودی HTTP باید از نظر Content-Type، طول بدنه، فیلدهای مجاز و بازه مقادیر بررسی شود. cPanel به پیکربندی فرایند، نسخه Node و مسیر public مناسب نیاز دارد.

**کار ویژه این مأموریت:** از افشای توکن، تزریق ورودی، داده خصوصی و URL ناامن جلوگیری کن؛ کنترل‌ها را با تست منفی بررسی کن.

سطح حمله: ورودی نامعتبر، JSON خراب، نامحدود بودن حجم درخواست و نشت اسرار. سیاست least-privilege و عدم ثبت token در log الزامی است.

## نمونه اجرای قابل بازرسی

فایل اجرایی موجود در پروژه: `academy/fezi-100k/examples/node_cpanel/server.mjs`.

```javascript
import http from 'node:http';
const app=http.createServer((req,res)=>{
  res.writeHead(200,{'content-type':'application/json'});
  res.end(JSON.stringify({ok:true,method:req.method}));
});
app.listen(3000,'127.0.0.1');
```

دستور اجرا: `PORT=3001 node academy/fezi-100k/examples/node_cpanel/server.mjs`

ورودی نمونه: `POST /api/tasks با {"title":"بررسی","hours":2}`

خروجی مورد انتظار: HTTP 201، JSON شامل item با title و hours؛ برای hours منفی HTTP 422

خروجی باید با اجرای واقعی برنامه بررسی شود؛ متن بالا تنها انتظار آزمون است.

## خطاهای رایج، موارد مرزی و عیب‌یابی

برای HTTP 415 مقدار Content-Type را به application/json تغییر بده. JSON خراب باید 400 و ورودی نامعتبر باید 422 بگیرد. در هاست واقعی logها و startup file را جدا بررسی کن.
