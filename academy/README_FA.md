# FEZI Studio Academy — بانک ۱۰۳٬۰۱۷ تسک در ۲۳ حوزه

**تعریف دقیق:** هر رکورد یک *تمرین/تسک ساختاریافته* است: شرح مسئله، حوزه، سطح، مرحله، خروجی مورد انتظار، ۵ معیار پذیرش، راهنمای محدودیت و شناسه یکتا. رکوردها با ترکیب قطعات موضوعی تألیف‌شده توسط ما به‌شکل قطعی ساخته شده‌اند. **این مجموعه شامل ۱۰۳٬۰۱۷ جواب آماده، اجرای موفق مدل، آموزش وزن‌های مدل، LoRA آموزش‌دیده یا ۱۰۳٬۰۱۷ آزمون عملکردی واقعی نیست.**

## محتوا

- `catalog.json`: تعداد تسک‌ها، موضوع‌ها، هش SHA-256 همه ۴۱۷ فایل و راهنمای محدودیت.
- `shards/<category>/NNNN.jsonl.gz`: JSON Lines فشرده (حداکثر ۲۵۰ تسک در هر فایل). این ساختار برای RAM محدود cPanel مناسب‌تر از خواندن یک فایل بسیار بزرگ است.
- `CATALOG_COUNTS.csv`: فهرست حوزه‌ها و شمارش.
- `../scripts/build-academy.py`: منبع قابل‌بازتولید ساخت تمرین‌ها، بدون دانلود فایل خارجی.
- `../scripts/run-academy.mjs`: اجرای تدریجیِ واقعی تمرین‌ها با یک مدل **متصل** و ثبت خروجی؛ پیش‌فرض صرفاً `--dry-run` برای آزمایش مسیر است.

## نمونه رکورد

```json
{
  "id": "chatgpt_mcp-00001",
  "category": "chatgpt_mcp",
  "kind": "guided_task_and_evaluation",
  "task": "شرح تمرین فارسی در نسخه ساخته‌شده",
  "expected_format": "نمونه JSON-RPC",
  "acceptance_criteria": ["۵ معیار متفاوت برای پذیرش و ارزیابی"],
  "review_type": "rubric_manual_or_ai"
}
```

## API — بعد از ورود مدیر

- `GET /api/academy/catalog` → تعداد دسته‌ها و تسک‌ها.
- `GET /api/academy/tasks?category=deployment&page=1&limit=10` → صفحه تمرین‌ها، حداکثر ۵۰ رکورد.
- `GET /api/academy/task?id=deployment-00001` → یک تسک.
- `GET /api/academy/recommend?id=deployment-00001` → **پیشنهاد اولیه مبتنی بر قواعد**، نه رتبه‌بندی واقعی مدل‌های آزمایش‌شده.
- `POST /api/academy/attempt` با `{ "taskId": "deployment-00001", "provider": "ollama", "model": "qwen2.5-coder:7b" }` → ارسال تسک به مدل متصل و ثبت یک پاسخ *بدون نمره تأییدشده*.
- `POST /api/academy/progress` با `{ "taskId": "deployment-00001", "status": "needs_review", "score": 2, "notes": "..." }` → ثبت ارزیابی **مدیر/بازبین**.
- `GET /api/academy/progress` → خلاصه پیشرفت و خطاهای ثبت‌شده.

## استفاده دسته‌ای (بدون اتکا به API پولی)

```bash
# فقط نمایش ۵ تسک؛ هیچ مدلی اجرا نمی‌شود
npm run academy:run -- --category deployment --limit 5 --dry-run

# زمانی که Ollama روشن و مدل دریافت شده است:
npm run academy:run -- --category deployment --limit 5 --provider ollama --model qwen2.5-coder:7b

# استفاده از سرویس پولی فقط با قبول صریح هزینه:
npm run academy:run -- --category chatgpt_mcp --limit 5 --provider openai --allow-paid
```

در اجرای دسته‌ای سقف هر فراخوانی ۱۰۰ تمرین است. نتایج به‌صورت خط‌به‌خط در `DATA_DIR/academy/runs` نگهداری می‌شوند. یک اجرا بعدی پاسخ‌های موفق قبلی را رد می‌کند. شکست‌ها ثبت می‌شوند و اجرا متوقف می‌شود؛ ۱۰۳ هزار فراخوانی هزینه‌زا خودکار آغاز نخواهند شد.

## شیوه افزایش مهارت واقعی

۱. یک معیار و تسک معین انتخاب شود؛ ۲. از مدل واقعی خروجی بگیریم؛ ۳. تست یا انسان به پاسخ نمره بدهد؛ ۴. شکست در `progress` ثبت شود؛ ۵. بعد از اصلاح، دوباره همان تسک آزموده شود؛ ۶. فقط داده دارای **پاسخ معتبر و مجوز مناسب** می‌تواند برای ساخت dataset آموزش نظارت‌شده (SFT) استفاده شود. برای LoRA به موتور آموزش، سخت‌افزار، tokenizer، سازگاری معماری و اجازه استفاده از داده نیاز است. کد این بسته وزن مدل‌ها را تغییر نمی‌دهد.

## حوزه‌های خاص

- **Hugging Face (۸۵۰ تسک):** تمرین‌های *کشف و اعتبارسنجی مدل* بر اساس دستورالعمل رسمی Hugging Face هستند؛ ادعا نمی‌کنیم ۸۵۰ مدل یا تکلیف موجود را در لحظه از سایت دریافت کرده‌ایم. مدل‌های زنده با ابزار جست‌وجوی Hub و API فعلی بررسی می‌شوند.
- **NSFW/بزرگسال (۹۰۰۰ تسک):** طراحی محتوای متناسب با بزرگسالان، سیاست انتشار، رضایت، حریم خصوصی و سن؛ نه مجوز دورزدن قوانین یا استفاده از دارایی‌های بدون حقوق انتشار. قابلیت ساخت تصویر/ویدیو صریح توسط مدل مستقل و مجاز، در این بسته موجود نیست.
- **کپی وب‌سایت و اپ:** تنها بازآفرینی مستقل صفحات عمومی یا کار روی پروژه‌های متعلق به کاربر/دارای مجوز. عبور از login، DRM و استخراج فایل‌های خصوصی به عنوان قابلیت اضافه نشده است.
- **امنیت:** نمونه‌های ممیزی و کدنویسی دفاعی روی محیط مجاز.
- **درک تصویر/ویدیو:** تسک‌ها به مدل multimodal و فایل واقعی نیاز دارند. مدل GGUF متنی به‌تنهایی ویدیو را نمی‌بیند.
- **مکالمه و زبان:** نمونه‌های زبان‌های متنوع برای تمرین؛ نه ادعای آموزش یا پوشش تمامی زبان‌های دنیا.
