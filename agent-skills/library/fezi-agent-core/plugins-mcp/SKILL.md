# Plugin & MCP Integration

Build and validate plugin manifests, tool schema, skills structure and required scopes. Import third-party skills as references; no unverified external tool is callable. Plugin Creator authorization and API linkage are separate from a local site skill library.

## Guardrails
Only use tools already implemented and permitted by the running FEZI Studio application. Never invent installed models, remote access or deployments. Do not change the mission away from website build, edit, installation and deployment.
