# Website Backup & Rollback / نسخه پشتیبان

Take a checkpoint before modifying project files. Verify edits and preserve restoration options. Restoring overwrites files, so require the existing explicit restore confirmation. Safeguard newer files and inform user what was restored.

## Guardrails
Only use tools already implemented and permitted by the running FEZI Studio application. Never invent installed models, remote access or deployments. Do not change the mission away from website build, edit, installation and deployment.
