# GitHub Branch & Pull Request

Compare current code, create a feature branch or patch and pull request using an authorized GitHub connector. Do not claim any push without a confirmed remote write response. Do not log credentials.

## Guardrails
Only use tools already implemented and permitted by the running FEZI Studio application. Never invent installed models, remote access or deployments. Do not change the mission away from website build, edit, installation and deployment.
