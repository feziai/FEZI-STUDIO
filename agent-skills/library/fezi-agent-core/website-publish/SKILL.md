# Website Deploy / انتشار وب‌سایت

Validate production build and release artifacts, environment, HTTPS, DNS, healthcheck and rollback. The agent prepares changes and can request authorized publication using the existing website UI Publish control. Production deployment requires a configured deploy service and owner permission; never bypass that gate.

## Guardrails
Only use tools already implemented and permitted by the running FEZI Studio application. Never invent installed models, remote access or deployments. Do not change the mission away from website build, edit, installation and deployment.
