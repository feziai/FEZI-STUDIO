# Website Install / نصب پروژه

Detect Node or static app layout, inspect package manifest, generate environment template without secrets, prepare install commands. On servers, installation and service restart require an authorized execution runner and must be tested. Do not execute arbitrary user-supplied commands or claim remote installation without a real tool result.

## Guardrails
Only use tools already implemented and permitted by the running FEZI Studio application. Never invent installed models, remote access or deployments. Do not change the mission away from website build, edit, installation and deployment.
