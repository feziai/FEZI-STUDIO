# FEZI Studio — نسخه کامل انتشار v1.01

**این پروژه روی بسته کامل قبلی ساخته شده است.** همه فایل‌های نسخه پایه حفظ شده‌اند. این فایل ZIP یک وب‌اپ کامل Node.js است و در گوشی Android با بازکردن `index.html` به‌تنهایی اجرا نمی‌شود؛ لازم است روی سرور Node.js 22+ نصب و از آدرس سایت در مرورگر استفاده شود.

## نکات مهم برای راه‌اندازی

1. ZIP را باز کنید و محتوای ریشه را در GitHub یا مسیر برنامه Node.js در cPanel قرار دهید؛ فایل‌های `server.js` و `package.json` باید در ریشه باشند.
2. در cPanel یک برنامه Node.js 22+ با startup file برابر `server.js` ایجاد کنید. متغیرهای محیط را **در محیط امن هاست** بگذارید، نه در GitHub، نه در HTML و نه در این چت.
3. از `.env.example` برای فهرست متغیرها استفاده کنید؛ مقادیر `APP_PASSWORD`، `SESSION_SECRET` و `PUBLIC_BASE_URL` را تنظیم کنید. در صورت فعال بودن نیازهای سرویس‌های دیگر، کلیدهای مرتبط را در محیط تنظیم کنید.
4. در محیط مناسب `npm test` را اجرا کنید و سپس برنامه را از cPanel/Process Manager اجرا نمایید. **اجرای صرف فایل HTML بدون سرور کافی نیست**.
5. برای تست صفحه‌ها `/`, `/fa/`, `/prompts`, `/prompt-creator`, `/telegram-builder`, `/studio`, `/faq`, `/arina-live`, `/admin/operations` را باز کنید. مسیر آخر نیازمند ورود مدیر است.
6. اتصال ایمیل واقعی نیازمند `RESEND_API_KEY` و `EMAIL_FROM` معتبر است؛ بدون آن درخواست تأیید ایمیل خطای 503 می‌دهد تا نتیجه ساختگی نباشد. ورود Google/Apple نیازمند Client ID/Secret و callback معتبر و توسعه نهایی است.

## قابلیت‌های پیاده‌سازی‌شده در v1.01

- کتابخانه پرامپت قبلی همراه ۴٬۰۰۰ قالب **جدید و اصلی FEZI** و ۹۱ پرامپت موجود. قالب‌ها **آرشیو واقعی انتقال‌یافته از GeneratePrompt نیستند** و تصاویر مشترک صرفاً نمونه سبک هستند.
- `/prompt-creator`: پرامپت‌ساز دسته‌بندی‌شده، کپی و استفاده در استودیو، اشتراک‌گذاری با نام پروفایل ثبت‌نام‌شده پس از رضایت کاربر و تأیید مدیر.
- `/profile`: پروفایل قدیمی با امکانات جدید تغییر رمز، کدهای بازیابی یک‌بارمصرف و درخواست تأیید ایمیل با سرویس ایمیل قابل پیکربندی.
- `/telegram-builder`: ساخت سورس ZIP ربات تلگرام با دکمه‌ها و پشتیبانی اختیاری AI؛ API Key و Bot Token در سورس خروجی ذخیره نمی‌شوند.
- `/admin/operations`: پنل خصوصی برای درخواست تغییرات، وضعیت، شواهد واقعی کار، آرشیو تصاویر آرینا، صف کلیپ‌های در انتظار رندر و موتور RAG خصوصی.
- دانش قابل بازیابی RAG: ایندکس خصوصی متنی حداکثر ۲۰۰ میلیون بایت، فقط پس از تأیید مدیر و ارائه مدرک به عامل عرضه می‌شود؛ این کار Fine-tuning وزن مدل نیست.
- `/fa/`, `/fa/ai/<model-id>`: صفحات فارسی مستقل کنار صفحات انگلیسی؛ `/sitemap-languages.xml` و لینک‌های `hreflang` برای این مسیرها. تمام بخش‌های سایت هنوز به همه زبان‌ها ترجمه نشده‌اند.
- ویدیوی تست CPU آرینا: ۴ ثانیه حرکت آرام قاب روی عکس اصلی؛ **نه رقص، نه تکلم و نه رندر مولد واقعی**. در پنل خصوصی نمایش داده می‌شود.
- اسکریپت اپراتوری استریم YouTube/Instagram روی ویدیوهای از پیش تأییدشده، **غیرفعال به‌طور پیش‌فرض**. مستندات در `docs/ARINA_RELEASE_v101_FA.md`.

## وضعیت آزمون و موارد غیرمتصل

- `node --test`: **۵٬۴۷۹ / ۵٬۴۷۹** تست محلی موفق.
- Smoke Test HTTP: **۳۵ / ۳۵** مسیر/عملیات آزمایشی موفق.
- `npm run academy:batch01`: **۲۵۰ / ۲۵۰** بررسی محلی در سه محیط مشترک برای ۲۵ درس پیش‌نویس؛ تعداد درس‌های تأییدشده RAG در بسته اولیه صفر است.
- **هیچ سرویس بیرونی در آزمایش‌ها به‌عنوان متصل تأیید نشده**؛ سرویس‌هایی مانند OpenAI API، OpenRouter، Google Sign-in، Resend، GitHub write، Telegram live، پرداخت، GPU و YouTube/Instagram Live نیازمند تنظیمات/مجوز و آزمون مستقل‌اند.
- آرشیو ۴٬۰۰۰ پرامپت منبعی همراه تصاویر اختصاصی دریافت نشده؛ این نسخه فقط سیستم واردسازی موجود و ۴٬۰۰۰ قالب اختصاصی FEZI را دارد.

## امنیت و حق نشر

توکن‌ها، secretها و کلید استریم فقط در متغیرهای محیطی سرور ثبت شوند. انتشار پرامپت/آثار کاربران به‌صورت اختیاری و با تأیید مدیر است. موسیقی دارای حق نشر تنها با مجوز قابل پخش است. آواتار آرینا به‌عنوان شخصیت مجازی معرفی شود. صفحات ادمین و دانش باید خارج از دسترسی کاربر عادی بمانند.

جزئیات فنی و داده آزمون در `QA-v1.01-FA.json` و راهنمای استریم در `docs/ARINA_RELEASE_v101_FA.md` آمده است.
