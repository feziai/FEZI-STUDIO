# FEZI STUDIO — نسخه یکپارچه آماده انتقال به هاست (۸ نوامبر ۲۰۲۶)

**یک پروژه Node.js 22، یک دامنه، یک نصب.** همه ماژول‌های وب در یک سورس قرار دارند. اتصال سرویس‌های خارجی مستقل و اختیاری است. سورس ChatGPT کپی نشده است؛ رابط چت جدید با هویت اختصاصی FEZI توسعه داده شده است.

## مهم‌ترین مسیرها

- `/` — صفحه اصلی FEZI Studio با لوگوی خرگوش-F
- `/ecosystem` — داشبورد یکپارچه ماژول‌ها و لینک‌های ۱۳ پلاگین خصوصی
- `/ai-chat` — انتخاب مدل از کاتالوگ OpenRouter با جست‌وجو، لوگوهای محلی، مدل رایگان و پولی، زبان خروجی و تایپ صوتی مرورگر در صورت پشتیبانی
- `/pricing` — بسته‌های ۱، ۵، ۷، ۱۰ و ۲۰ میلیون تومان و شارژ دلخواه، گردش فاکتور و موجودی حساب
- `/fezipay/` — مینی‌وب‌سایت FeziPay داخل همان دامنه (پرداخت و تسویهٔ واقعی تا اتصال تأییدکننده غیرفعال است)
- `/builder` — FEZI Agent برای ساخت و ویرایش وب‌سایت
- `/fezi-agent/skill-creator` — ساخت اسکیل
- `/plugins` — فهرست ابزارها و پلاگین‌ها
- `/plugins/telegram-builder` و `/plugins/telegram-manager` — ربات‌ساز و مدیریت ربات
- `/plugins/free-models` — کاتالوگ مدل‌های رایگان

## نصب روی سرور Node.js 22

1. کل پوشه `FEZI_STUDIO` را از ZIP استخراج کن.
2. روی VPS یا هاست با Node.js 22، پوشه را آپلود کن. **فقط پوشه `public/` کافی نیست**؛ سرور و ماژول‌ها هم لازم هستند.
3. `cp .env.example .env`؛ برای `APP_PASSWORD` و `SESSION_SECRET` دو مقدار قوی، تازه و جداگانه تنظیم کن.
4. حتماً کلیدهای قبلی که در متن/فایل‌های گفتگو ارسال شده بودند را **ابطال و بازتولید** کن. هیچ کلید خصوصی در ZIP یا GitHub عمومی قرار نده.
5. تنظیم HTTPS و دامنه را در Caddy/Nginx یا cPanel انجام بده؛ `PUBLIC_BASE_URL=https://YOUR-REAL-DOMAIN` و `COOKIE_SECURE=true`.
6. روش VPS/Docker: `docker compose -f compose.final.yaml up -d --build` (نیازمند Docker و Docker Compose در سرور است).
7. روش بدون Docker/Node: `node --version` باید 22+ باشد؛ سپس `npm start` را با Process Manager دائمی اجرا کن. پوشه `DATA_DIR` باید قابل‌نوشتن و پایدار باشد.
8. مسیرهای `/health`، `/ecosystem`، `/ai-chat`، `/pricing`، `/plugins` و `/fezipay/` را تست کن.
9. برای FEZI Agent رایگان، یک OpenRouter API key تازه در `OPENROUTER_API_KEY` تنظیم کن و `OPENROUTER_MODEL=openrouter/free` بماند. سهمیه رایگان وابسته به ارائه‌دهنده است.
10. برای استفاده از مدل‌های **پولی**، `FEZI_RESELLER_OPENROUTER_KEY` و `FEZI_COMMERCIAL_OPENROUTER_ENABLED=true` فقط پس از بررسی محدودیت‌ها و تست معتبر تنظیم شود.

## قیمت، شارژ، پرداخت

- قیمت نمایشی مدل‌ها = نرخ کاتالوگ OpenRouter × 1.20 برای هزینه توکن ورودی و خروجی؛ هزینه نهایی در صورت موجود بودن از هزینه مصرفِ تأییدشده در پاسخ سرور OpenRouter × 1.20 محاسبه می‌شود.
- شاخص `usage.cost` ممکن است هزینه کش، استدلال یا مواردی را شامل شود که با ضرب ساده تعداد توکن قابل محاسبه نباشند.
- مدل‌های image/video و برخی مدل‌های چندرسانه‌ای فعلاً در کاتالوگ فهرست می‌شوند، اما مسیر چت پولی **فقط متن** است. اجرای تمام این مدل‌ها به API/worker متناسب نیاز دارد.
- `FEZI_TOMAN_PER_USD` باید نرخ واقعی و به‌روز تنظیم‌شده توسط مالک باشد. تا تعیین نرخ، ایجاد فاکتور غیرفعال است.
- بسته‌ها به تومان هستند؛ اعتبار مصرفی با تبدیل به دلار محاسبه می‌شود. نرخ، هزینه جانبی و مالیات باید قبل از خرید شفاف اعلام شوند.
- **خرید خودکار فعال نیست**: FeziPay فعلاً صفحه اطلاعاتی/پیش‌نمایش است. سفارش فقط `pending` می‌شود و به‌تنهایی اعتبار نمی‌افزاید.
- تأیید دستی فقط با `FEZI_MANUAL_CREDIT_CONFIRM_ENABLED=true` و ورود مدیر پس از احراز مستقل واقعی مبلغ/شبکه/گیرنده/شناسه تراکنش انجام می‌شود؛ این گزینه پیش‌فرض خاموش است. راه‌اندازی درگاه حرفه‌ای تولید نیازمند سرویس تأیید مستقل، انطباق حقوقی، تسویه و مدیریت بازگشت وجه است.
- دسترسی مدل پولی صرفاً پس از ثبت اعتبار تأییدشده برقرار می‌شود؛ برنامه اعتبار/رزرو/کسر و بازگشت رزرو در خطا دارد. هیچ اعتباری از ورودی دلخواه مرورگر ایجاد نمی‌شود.

## Telegram و Plugin Creator

- از BotFather ربات جدید بساز؛ توکن جدید و webhook secret را در `.env` وارد کن؛ HTTPS و اکانت مدیر را تنظیم کن و بعد از تست `npm run telegram:factory:setup -- --apply` را اجرا کن.
- ربات مرکزی منوهای `/newbot /mybots /plugins /agent /models /pricing /fezipay` را به همان وب‌سایت وصل می‌کند؛ راهنمای ساخت و خروجی ۴ چارچوب ربات در ماژول‌های قبلی محفوظ مانده است.
- پلاگین `FEZI Telegram Bot Maker` در ChatGPT به نسخه 0.5.1 به‌روزرسانی شده است؛ **نصب این ZIP به‌خودی‌خود پلاگین‌های خصوصی ChatGPT را برای تمام کاربران فعال نمی‌کند**؛ نصب/مجوز آن‌ها در ChatGPT جداست.
- برای بانک مهارت‌ها، فایل فشرده `references/FEZI_ALL_PROMPTS_AND_SKILLS_MASTER.json.gz` موجود است؛ جست‌وجوی مدیر از `/api/fezi/agent/master-skills?q=openrouter` استفاده می‌کند. مهارتِ فهرست‌شده به معنی مهارتِ نصب‌شده یا اجازه اجرای آن نیست.

## پشتیبانی زبان

- در چت جدید، زبان پاسخ می‌تواند «خودکار» یا یکی از زبان‌های رایج انتخاب شود؛ موفقیت خروجی وابسته به توانایی مدل انتخاب‌شده است.
- همهٔ رابط‌های UI هنوز به تمام زبان‌های جهان ترجمه نشده‌اند؛ رابط اصلی فارسی با بخش‌های انگلیسی است.

## کنترل کیفیت انجام‌شده

- آزمون کامل Node.js: **۵٬۶۴۸ موفق، صفر شکست** در محیط تست.
- آزمون HTTP محلی: ۱۸ مسیر عمومی با پاسخ ۲۰۰؛ ۴ مسیر حساب/پرداخت بدون ورود با پاسخ ۴۰۱.
- آزمون اختصاصی محاسبه ۲۰٪، جلوگیری از اعتباردهی قبل از تأیید، استفاده از هزینه واقعی OpenRouter، جست‌وجوی مهارت‌ها: موفق.
- اسکن الگوهای رایج کلیدهای واقعی در سورس بدون مورد آشکار.
- اجرای Docker واقعی در محیط تولید **تست نشده است** چون Docker در محیط تهیه بسته موجود نبود.
- تماس واقعی با OpenRouter پولی، تسویه FeziPay، سرویس Telegram Bot API و فعال‌سازی عمومی پلاگین‌ها **انجام نشده است**.
