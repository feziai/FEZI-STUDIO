# FEZI Studio v1.01 — ادامه توسعه و موارد باقی‌مانده

نسخه انتشار مطابق درخواست مالک همچنان **v1.01** است؛ این بسته بر پایه ZIP کامل `FEZI_STUDIO_v1.01_FULL_RELEASE_READY.zip` ساخته شده و از صفر بازنویسی نشده است. فایل‌های قبلی حفظ شده‌اند. برای اجرای کل برنامه بازکردن HTML در اندروید کافی نیست؛ باید پروژه روی Node.js 22+ اجرا شود.

## امکانات تکمیل‌شده در این مرحله، با آزمایش محلی

1. **ثبت‌نام و امنیت:** فرم صفحه Profile اکنون username یکتا (۳ تا ۳۰ کاراکتر `[a-z0-9_]` با حداقل یک حرف لاتین)، نام نمایشی، ایمیل اختیاری، رمز ۱۰+ کاراکتری و پذیرش قوانین دارد. ورود با یوزرنیم یا ایمیل مجاز است. نسخه اصلی `createStudioV15` برای سازگاری حساب‌های قدیمی حفظ شده و شناسه‌های پیشین تغییر نمی‌کنند. CAPTCHA روی سرور اصلی به‌طور پیش‌فرض الزامی است. تصاویر آن SVG و **۶ کاراکتر تصادفی از الفبای بدون حروف گیج‌کننده** هستند؛ token فقط شناسه/HMAC است و پاسخ داخل توکن قرار نمی‌گیرد. درخواست‌ها محدود، کوتاه‌مدت و یک‌بارمصرف‌اند. پنج تصویر مرجع SIZI85 بدون دست‌کاری در `references/captcha/` قرار دارند، اما پاسخ ثابت CAPTCHA نیستند.
2. **امنیت حساب:** بازیابی با کدهای یک‌بارمصرف، تغییر رمز، افزودن یا اصلاح ایمیل با ارائه رمز فعلی، و ارسال کد تأیید فقط در صورت اتصال Resend. تغییر ایمیل نشست‌های قبلی را باطل می‌کند. بدون سرویس ایمیل هیچ پیامی تحویل‌داده‌شده اعلام نمی‌شود.
3. **پروفایل عمومی:** مسیر `/u/<username>`، نمایش آثار عمومی تأییدشده (تصاویر و ویدیو)، فهرست محصولات تأییدشده و آواتار انتخابی. ایمیل، آثار خصوصی، رمزها و اطلاعات پرداخت کاربران عمومی نیستند. آواتار عمومی آپلودشده از `/api/creator/avatar/<username>` با بررسی مالکیت حساب ارائه می‌شود.
4. **کیف پول سازنده:** مسیرهای خصوصی `/api/creator/wallet` و `/api/creator/payout-wallets` از BNB(BSC)، TRX و USDT در شبکه‌های BEP20/TRC20/ERC20 پشتیبانی می‌کنند. فقط فرمت آدرس بررسی می‌شود؛ هیچ تراکنش، تسویه یا اثبات مالکیت کیف پول در این بخش انجام نمی‌شود. آدرس‌های اصلی مالک از `core/arina-wallets.json` تغییر نکرده‌اند.
5. **Marketplace:** صفحه `/marketplace` و API ثبت محصول با عنوان، دسته، قیمت، توضیح، تأیید حقوق انتشار و فایل خصوصی اختیاری حداکثر ۱۰ MB. وضعیت اولیه `pending_review` است؛ فقط مدیر می‌تواند محصول را در `/admin/marketplace` یا `/admin/dashboard-v101` تأیید/رد و از لینک خصوصی بازبینی فایل استفاده کند. حداقل قیمت ۳ دلار است؛ سقف برای غیر از مدل AI یک‌میلیون دلار؛ کارمزد پرامپت ۵٪ و سایر موارد ۱۵٪ با محاسبه برحسب سنت و ثبت در داده‌ها. **درگاه واقعی اتصال ندارد**؛ سفارش تنها در وضعیت `awaiting_payment_provider` ثبت می‌شود، فایل پولی تحویل نمی‌شود و فروشنده تسویه دریافت نمی‌کند. همچنین خرید اعتبار API با حداقل ۱۰ دلار فعلاً فقط quote در حالت فاقد اتصال پرداخت است.
6. **۲۸۹ ابزار متن‌باز:** فهرست کاربر در `config/open-source-registry-v101.json` (P0=30، P1=54، P2=184، P3=21) بدون حذف ورودی وارد شده و در `/opensource` و `/api/opensource` جست‌وجو می‌شود. هر ابزار دارای لینک مخزن، کاربرد، سطح اولویت و وضعیت `not-installed` است. این پروژه‌ها دانلود یا اجرا نشده‌اند و مجوز هرکدام هنوز برای استفاده تجاری باید بررسی شود.
7. **چندزبانه و SEO:** ۸ زبان (EN, FA, DE, FR, ES, AR, TR, RU) × ۷ موضوع خدماتی = ۵۶ صفحه **واقعاً متن‌دار** در `/lang/<locale>/<service>` با عنوان، توضیح، canonical و `hreflang`. سایت‌مپ آنها `/sitemap-i18n.xml` است که از `robots.txt` معرفی می‌شود. سایر زبان‌ها و صفحات هنوز ترجمه/بازبینی نشده‌اند و ادعای ۵۰ زبان کامل مطرح نمی‌شود.
8. **مدیریت:** داشبورد مالک `/admin/dashboard-v101` تعداد کاربران، فروشنده‌های در انتظار، سفارش‌ها، ابزارهای فهرست‌شده و وضعیت ارائه‌دهندگان را جدا نشان می‌دهد. ابزارهای قبلی `/admin/operations`، `/admin/assistant`، `/admin/prompts`، `/admin/faq` و `/admin/community` حذف نشده‌اند. دسترسی مدیر با نشست مستقل مالک محدود می‌شود.
9. **آرینا:** مشاهده روم و تاریخچه همچنان برای مهمان ممکن است؛ ارسال پیام و رأی فقط با حساب FEZI. پاسخ متنی بدون اتصال مدل واقعی **پیش‌فرض دمو نمی‌دهد** (`ARINA_DEMO_MODE=false`). برنامه‌ریزی کلیپ و رفرنس‌های قبلی آرینا حفظ شده‌اند؛ این تغییر رندر GPU، لایو واقعی ۲۴ساعته یا استریم خارجی نمی‌سازد.
10. **آماده‌سازی استقرار:** `npm run release:doctor` تنظیمات مهم را فقط از نظر وجود/ساختار بررسی می‌کند، بدون چاپ هیچ مقدار محرمانه‌ای. `DATA_DIR` باید خارج از محل جایگزینی فایل‌های پروژه و در محل پایدار باشد. فایل ZIP منبع برای GitHub یا cPanel است؛ نه APK نصب‌شدنی.

## ترتیب کارهای باقی‌مانده و وابستگی‌ها

- **P0 — اتصال واقعی سرویس ایمیل و Google/Apple OAuth:** OAuth و ورود اجتماعی از طرف FEZI هنوز پیاده‌سازی و آزمایش end-to-end نشده‌اند. نیازمند ثبت اپ نزد ارائه‌دهنده، HTTPS/callback و تنظیمات محرمانه هستند. از اتصال شخصی ChatGPT Plus به وب‌سایت به‌عنوان API استفاده نمی‌شود؛ برای سرویس OpenAI باید API Key مجزا با هزینه/سهمیه خودش تنظیم شود.
- **P0 — تأیید پرداخت رمزارز:** دریافت تراکنش و شناسایی شبکه/ارز/شناسه کاربر، کنترل تعداد تأیید بلاک، تشخیص مبالغ و رسیدهای تکراری، لغو/بازپرداخت، دفترکل حسابداری، تسویه امن فروشنده و کنترل حقوقی/مالیاتی هنوز به پردازشگر و آزمون واقعی نیاز دارد. بدون این مرحله محصول پولی و اعتبار API قابل تحویل نیست.
- **P0 — پیکربندی AI/Worker:** Ollama/سرویس AI، GPU worker برای تصویر/ویدیو و آرینا، تست توان چندکاربره و محدودیت سهمیه هنوز نیازمند سرور واقعی و هزینه سخت‌افزار/سرویس هستند. کتابخانه ۲۸۹ ابزار، کاتالوگ است و هیچ‌کدام `verified running` نیستند.
- **P1 — آرینا و پخش بیرونی:** کلیپ‌های رقص/تایپ/واکنش باید از رفرنس‌های مجاز تولید، از نظر پیوستگی و فریم آغاز/پایان بررسی و سپس استریم HLS/RTMP به YouTube/Instagram تنظیم و در سرویس‌های مقصد تأیید شوند. داشتن عکس و استوری‌بورد معادل ویدیوی ساخته‌شده نیست. موسیقی تجاری بدون مجوز پخش استفاده نشود.
- **P1 — آرشیو GeneratePrompt:** واردساز JSON/JSONL آماده است، ولی آرشیو واقعی کامل سایت در این بسته نیست. داده واقعی/رسانه‌های دارای مجوز باید با ورود مالک وارد شود. ۴۰۰۰ قالب تولیدی FEZI با آرشیو منتقل‌شده از سایت اصلی یکی نیستند.
- **P1 — بهبود محتوای SEO به ۵۰ زبان:** هشت زبان اصلی آماده‌اند؛ افزودن ترجمه معتبر و بازبینی هر صفحه قبل از افزودن به sitemap. ساخت صفحات توخالی یا کلمات کلیدی جعلی انجام نمی‌شود.
- **P1 — آزمایش استقرار روی هاست:** GitHub write، cPanel، HTTPS، WebSocket/SSE و cron تلگرام در محیط واقعی میزبان هنوز بررسی نشده‌اند. نسخه آماده بارگذاری ZIP است ولی منتشر نشده.
- **P2 — اتوماسیون بهبود و ۱۰۰٬۰۰۰ مأموریت:** صف آموزشی و ۲۵ درس اول حفظ شده‌اند. افزایش درس‌ها به بسته‌های ۲۵تایی همراه شاهد، QA و تأیید مالک؛ بدون یادگیری از داده خصوصی کاربران یا دست‌کاری خودکار تولید.

## اجرا و آزمایش

```sh
npm test
npm run release:doctor
# سپس با تعیین Environment Variables امن:
npm start
```

مقادیر `APP_PASSWORD` حداقل ۱۰ کاراکتر و `SESSION_SECRET` حداقل ۲۴ کاراکتر باید متفاوت باشند. روی سایت HTTPS، `COOKIE_SECURE=true` و `PUBLIC_BASE_URL=https://...` و `DATA_DIR` دائمی لازم‌اند. توکن تلگرام و کلیدهای OpenRouter/HF/OpenAI باید در Secrets هاست باشند، نه در سورس یا چت.

## مرز ادعا

تست‌های `npm test` محلی هستند؛ HTTP محلی شامل ثبت‌نام، کپچا، کالا، مدیریت و صفحات جست‌وجو هم انجام شده است. این‌ها به‌معنای تأیید پرداخت واقعی، گوگل/اپل، مدل‌های GPU، ایمیل بیرونی یا ثبت سایت در موتورهای جست‌وجو نیستند.
