# FEZI Studio — کنترل از تلگرام یا ChatGPT

این نسخه یک مرکز کنترل مشترک برای سرور FEZI Studio فراهم می‌کند. وب‌سایت می‌تواند روی هر هاست سازگار با Node.js 22 مستقر باشد؛ تلگرام و ChatGPT فقط دو رابط برای فرمان‌دادن به همان سرور هستند. هر نصب مستقل، پروژه‌ها و داده‌های همان نصب را کنترل می‌کند.

## راه‌اندازی تلگرام

1. FEZI Studio را روی سرور دارای HTTPS راه‌اندازی کن. `PUBLIC_BASE_URL` باید آدرس همان سرور باشد.
2. توکن **تازه** یک ربات مدیر را در `TELEGRAM_FACTORY_BOT_TOKEN` قرار بده؛ آن را داخل چت یا GitHub قرار نده.
3. یک راز تصادفی برای `TELEGRAM_FACTORY_WEBHOOK_SECRET` و شناسه عددی حساب مدیر برای `TELEGRAM_FACTORY_ADMIN_CHAT_IDS` تنظیم کن.
4. `npm run telegram:factory:setup -- --apply` را از محیط سرور اجرا کن.
5. در گفتگوی خصوصی ربات، `/status`، `/projects`، `/mybots`، `/jobs PROJECT_ID` را امتحان کن.
6. برای ویرایش پروژه `/run PROJECT_ID شرح تغییرات` را بفرست، سپس کد اختصاصی `/confirm CODE` را طی ۵ دقیقه تأیید کن. هیچ ویرایشی پیش از تأیید آغاز نمی‌شود.
7. `/checkpoint PROJECT_ID` برای ساخت نقطه بازگشت است. دسترسی این فرمان فقط برای شناسه مدیر تعیین‌شده برقرار است.

**نکته:** اجرای کد یا نصب مدل به‌صورت خودکار تضمین نشده است؛ FEZI Agent تنها با ارائه‌دهنده AI معتبر و اسکیل‌های واقعاً متصل می‌تواند یک تسک را اجرا کند. ربات مرکزی نمی‌تواند بدون BotFather، توکن‌های ربات‌های جدید را صادر کند.

## اتصال ChatGPT

1. متغیر `FEZI_AGENT_MCP_TOKEN` را به یک راز تازه و تصادفی با حداقل ۳۲ نویسه تنظیم کن.
2. در سرویس دارای HTTPS، آدرس `https://YOUR_DOMAIN/mcp/fezi-agent` موجود است. این API یک MCP خصوصی JSON-RPC است و برای تماس‌ها هدر `Authorization: Bearer ...` می‌خواهد.
3. ابزارهای MCP موجود: `fezi_remote_status`، `fezi_remote_projects`، `fezi_remote_plugins`، `fezi_remote_jobs`، `fezi_remote_checkpoint` و `fezi_remote_start_agent`، علاوه بر اسکیل‌ها و تشخیص‌های قبلی.
4. قبل از استفاده مستقیم از داخل ChatGPT، باید کانکتور یا پلاگین اختصاصی ChatGPT را به این MCP متصل و روش احراز هویت پشتیبانی‌شده توسط پلتفرم را پیکربندی کنی. **صرف وجود این API به معنی اتصال خودکار پلاگین خصوصی ChatGPT نیست**. اگر پلتفرم OAuth لازم داشته باشد، راه‌اندازی یک درگاه احراز هویت OAuth جداگانه لازم است؛ این بسته چنین درگاهی ندارد.
5. `fezi_remote_start_agent` و `fezi_remote_checkpoint` بدون `confirm:true` رد می‌شوند. ابزارهای داخلی سرور به تأیید و مجوزهای مستقل خود وابسته‌اند.

## سطح دسترسی

- اطلاعات خصوصی از طریق رابط عمومی قابل خواندن نیست. تلگرام نیازمند Webhook Secret و شناسه مدیر است؛ ChatGPT MCP نیازمند توکن خصوصی خود است.
- Shell عمومی، اجرای دستورات آزاد سیستم‌عامل، دورزدن مجوز GitHub، نصب خودکار پلاگین‌های ChatGPT و اجرای پرداخت بدون تأیید وجود ندارد.
- توکن‌ها را هیچ‌وقت در فایل ZIP منتشرشده، متن پرامپت، چت یا مخزن GitHub قرار نده. کلیدهای قدیمی منتشرشده باید تعویض شوند.
- درخواست‌های ویرایش پروژه در حال حاضر در حافظه همان پردازش Node.js صف‌بندی می‌شوند و بدون مدل AI آماده اجرا کامل نمی‌شوند.

## پایش و عیب‌یابی

`npm test` و `node --test tests/fezi-remote-control.test.mjs` را اجرا کن. وضعیت `status`، وضعیت قطعی ارائه‌دهندگان خارجی نیست. در هاست اشتراکی با محدودیت اجرای دائمی Node.js، ممکن است Webhook و کارهای طولانی درست کار نکنند؛ VPS با HTTPS و ذخیره دائمی پیشنهاد می‌شود.
