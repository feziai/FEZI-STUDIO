# FEZI Studio v1.8 — Prompt Library

بخش `/prompts` شامل **۹۱ پرامپت تأییدشده و قابل کپی** در **۲۱ دسته** است. ۳۲ تصویر مفهومی محلی و برخی گالری‌های چندتصویری برای نمایش کارت‌ها به کار می‌روند. تصاویر پیش‌نمایش مفهوم را نشان می‌دهند و خروجی واقعی مدل تضمین‌شده نیستند.

- قابلیت‌ها: جستجوی متن، دسته‌بندی، فیلتر نوع، کپی مستقیم، انتقال به `/studio`، اشتراک‌گذاری لینک، صفحه مستقل، چند تصویر مرجع و سایت‌مپ.
- انتقال مجاز: `POST /api/admin/prompts/import` با احراز هویت مدیر و ثبت مجوز متن و رسانه. برای منابع بدون مجوز، فقط لینک منبع نشان داده می‌شود.
- تم: سفید غالب، آبی روشن و صورتی؛ لوگوی اصلی FEZI بدون تغییر.
- اصلاح امنیت: escape ایمن برای JSON اسکریپتی هنگام ورود متن پرامپت، جلوگیری از تزریق `</script>`.
- نصب نیازمند Node.js >=22 است، محتوای ZIP صفحه با بازکردن فایل در اندروید به‌تنهایی اجرا نمی‌شود.
- این کتابخانه ادعای واردسازی انبوه تمام مطالب شش سایت خارجی ندارد؛ فقط محتواهایی که حق انتقالشان تأیید شده، منتشر می‌شوند.
