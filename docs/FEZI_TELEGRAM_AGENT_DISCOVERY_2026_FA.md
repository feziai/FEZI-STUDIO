# فضی استودیو — راهنمای اجرای یکپارچه Telegram / FEZI Agent / MCP / مدل‌ها

## چیزهایی که در این نسخه واقعاً به سورس سایت اضافه شده‌اند
- Plugin Hub: /plugins
- ربات‌ساز: /plugins/telegram-builder
- کنترل‌پنل ربات‌ها: /plugins/telegram-manager
- کاتالوگ مدل‌ها و مخازن: /plugins/free-models
- ابزارهای شخصی FEZI Agent: /fezi-agent/tools
- MCP خصوصی FEZI Agent: POST /mcp/fezi-agent (نیازمند توکن تازه و قوی)
- فهرست عمومی انتخابی ربات‌ها: GET /api/plugins/telegram/public
- کاتالوگ اطلاعاتی: GET /api/fezi/discovery
- ربات مرکزی: POST /api/plugins/telegram/factory/webhook

## راه‌اندازی روی یک هاست Node.js 22
1. بستهٔ کامل پروژه را در مسیر برنامه نصب کنید یا پچ را روی همان نسخه پایهٔ ذکرشده اعمال کنید.
2. Node.js 22+ و فضای ذخیره‌سازی قابل نوشتن برای DATA_DIR لازم است.
3. متغیرهای APP_PASSWORD و SESSION_SECRET را به مقدار قوی و متفاوت تنظیم کنید.
4. PUBLIC_BASE_URL را روی دامنهٔ HTTPS واقعی سایت بگذارید.
5. اگر می‌خواهید هر روز برنامه‌ها و مدل‌های تازه **کشف** شوند: `FEZI_DISCOVERY_AUTO_REFRESH=true`.
6. برای دکمهٔ بروزرسانی دستی مدیر: `FEZI_DISCOVERY_ADMIN_REFRESH=true`.
7. `npm test` و سپس `npm start` را اجرا کنید.
8. از مسیر `/plugins/free-models` فهرست‌ها را بررسی کنید. وجود یک مدل به معنای نصب آن یا امکان اجرای استنتاج نیست.
9. در صورت نیاز `FEZI_AGENT_SHELL_ENABLED=true` فقط برای محیط مدیر فعال کنید؛ فقط چند دستور از پیش تعیین‌شده قابل اجراست.

### ساخت ربات مرکزی سازنده
1. از @BotFather یک **ربات جدید** بسازید. ربات مرکزی نمی‌تواند خودش از BotFather توکن صادر کند.
2. توکن را در Secret Manager سرور با نام `TELEGRAM_FACTORY_BOT_TOKEN` ثبت کنید.
3. یک مقدار تصادفی امن برای `TELEGRAM_FACTORY_WEBHOOK_SECRET` بسازید؛ از کاراکترهای انگلیسی، عدد، - و _ استفاده کنید، حداقل ۲۴ کاراکتر.
4. شناسه‌های عددی مدیران را با `TELEGRAM_FACTORY_ADMIN_CHAT_IDS` و کامای انگلیسی جدا کنید.
5. تنظیمات را با `npm run telegram:factory:setup` بدون تغییر تلگرام بررسی کنید.
6. **پس از عمومی‌شدن HTTPS و اجازه صاحب ربات**: `npm run telegram:factory:setup -- --apply`.
7. این دستور، `setWebhook` و `setMyCommands` و دکمه منوی Web App را روی Bot API واقعی اجرا می‌کند؛ اتصال تلگرام تا پیش از اجرای آن اثبات نشده است.
8. فرمان‌های /newbot، /mybots، /plugins و /models در ربات مرکزی فعال خواهند شد. توکن‌های ربات‌های فرعی را در پیام تلگرام نگیر، فقط در فرم HTTPS وارد کن.

### ربات‌هایی که با سایت ساخته می‌شوند
- خروجی بومی Node.js، grammY، Telegraf و aiogram موجود است؛ نصب وابستگی‌ها در سرور مالک صورت می‌گیرد.
- مدل نمایش عمومی/خصوصی از صاحب ربات پرسیده می‌شود؛ فهرست عمومی فقط opt-in.
- منوها و فرمان‌ها با setMyCommands و منوی WebApp تنظیم می‌شوند، و پاسخ‌های میزبانی‌شده امضای FEZI Studio دارند.
- فایل‌های نمونه *فاقد توکن خصوصی هستند*؛ توکن‌ها را در مخزن GitHub نگه ندارید.
- با `PUBLIC_BASE_URL` معتبر، مدیر می‌تواند ربات‌های متصل را ویرایش، بازرسی و جدا کند.

### FEZI Agent و MCP و Shell
- مأموریت اصلی FEZI Agent: ساخت، ویرایش، نصب و انتشار وب‌سایت (با تأیید دسترسی واقعی).
- کتابخانه اسکیل‌ها از قبل در سورس موجود است. صفحهٔ /fezi-agent/tools آن را جستجو می‌کند.
- endpoint خصوصی /mcp/fezi-agent فقط با `FEZI_AGENT_MCP_TOKEN` دارای طول ≥۳۲ و هدر Authorization باز می‌شود. برای ارائه عمومی در ChatGPT به OAuth استاندارد نیاز دارید؛ این bearer token جایگزین OAuth نیست.
- Shell سایت **پوستهٔ آزاد سیستم‌عامل نیست**؛ فقط دستورات تشخیصی اجازه‌دار مانند git-status، تست‌ها و node-version را اجرا می‌کند.
- نصب برنامه‌های GitHub، گرفتن اختیار سایر حساب‌ها، هزینه‌کرد و نشر خودکار تغییرات حساس مجاز نیست مگر دسترسی واقعی و قواعد تأیید/استقرار تعریف شود.

### مدل‌های رایگان و آپدیت روزانه
- OpenRouter: فقط شناسه‌های `:free` با هزینهٔ ورودی و خروجی صفر؛ `openrouter/free` در روتر Chat موجود است. محدودیت سهمیه و نرخ پابرجاست.
- Hugging Face: مخازن غیر gated؛ لایسنس، وزن و منابع باید برای اجرای هر مدل بررسی شود. نسخه‌ها/تگ‌ها را از صفحه خود مخزن ببینید.
- GitHub: مخازن دارای لایسنس شناسایی می‌شوند؛ کدهای آن‌ها بدون ممیزی نصب یا اجرا نمی‌شود.
- زمان‌بند ۲۴ ساعته تنها روی هاست فعال با `FEZI_DISCOVERY_AUTO_REFRESH=true` کار می‌کند.
- فایل `.github/workflows/fezi-daily-audit.yml` تست روزانه را در مخزن در صورت Push و فعال بودن GitHub Actions اجرا می‌کند؛ خودکار کد ناشناس را merge نمی‌کند.

### فایل Dotenv.txt و کلیدهای افشاشده
**کلیدهای موجود در فایل ارائه‌شده محرمانه و افشاشده تلقی شوند. پیش از اجرای واقعی همه را در سرویس‌های اصلی ابطال/تعویض کنید.** هیچ مقدار واقعی از آن فایل در این پچ، سورس یا نمونه dotenv کپی نشده است.

### وضعیت‌های مورد انتظار
- `CODE_READY`: کد آماده و تست محلی موفق.
- `CONFIG_REQUIRED`: نیازمند سرور HTTPS/کلید تازه/مجوز GitHub.
- `CONNECTED`: اتصال خارجی با تماس API موفق.
- `RUNTIME_VERIFIED`: رفتار واقعی در تلگرام یا موتور AI با تست end-to-end تأیید شده.

## مجوز ابزارهای آینده
- Transformers، LangChain، smolagents، LiteLLM و Flowise برای توسعهٔ بعدی نگهداری شده‌اند؛ نصب/وصل واقعی این نسخه نیستند.
- **n8n**: اگر کاربران بیرونی بخواهند از داخل FEZI Studio جریان‌کاری بسازند یا تغییر دهند، ممکن است لایسنس تجاری لازم شود؛ و صرفاً متن‌باز آزاد برای بازفروش نیست.
- Open WebUI: سرویس مستقل مرجع است، نه بخش نصب‌شده در این نسخه. پیش از یکپارچه‌سازی تجاری لایسنس بررسی شود.

## نتیجه
با یک پروژه Node.js یک سایت اصلی دارید و بخش‌های Telegram، Plugin Hub و FEZI Agent زیر همان دامنه کار می‌کنند. برای پردازش CPU/GPU سنگین، Worker جدا در آینده لازم است.

## اجرای API-first بدون Ollama / GPU
برای اجرای یکپارچهٔ وب‌سایت بدون دانلود وزن مدل، پس از تنظیم `.env` می‌توانید از `docker compose -f compose.api-first.yaml up -d --build` استفاده کنید. این روش سرویس Ollama سنگین را به‌صورت پیش‌فرض اجرا نمی‌کند، ولی برای Chat باید یک API معتبر و مجاز (مثلاً OpenRouter free) داشته باشید. برای دامنه HTTPS، تنظیم reverse proxy، TLS و COOKIE_SECURE ضروری است. Docker-compose عادی پروژه ممکن است Ollama را همراه سایت اجرا کند؛ در حالت API-first نیازی به آن نیست.
