# FEZI AGENT v0.77 — Arina: Continuous Full-HD Dance Pipeline

## هدف: ظاهر سایت بدون تغییر، فقط آرینا در حالت LIVE
- صفحه اصلی `/showcase` پلتفرم عمومی ساخت وب‌اپ، سایت، تصویر، ویدیو و برنامه است و ظاهر آن حفظ شده.
- صفحه آواتار `/arina-live` تنها نمای مشترک زنده این نسخه است؛ مدل‌های دیگر در گالری به شکل تصویر و برای سفارش ساخت/شخصی‌سازی باقی می‌مانند و استریم جدا ندارند.
- گفتار صوتی فعلاً غیرفعال است. فقط **پاسخ متنی** (اگر `ARINA_AI_ENABLED=true` و مدل قابل اجرا متصل باشد، واقعی؛ در غیر این صورت مشخصاً دمو).
- پیام‌ها و صحنه و زمان شروع از **یک سرور** هماهنگ می‌شوند. چند کاربر همزمان همان ویدیو و وضعیت را می‌بینند؛ درخواست‌های گروهی رأی‌گیری می‌شوند.
- دکمه‌های مستقیم اجرای رقص وجود ندارند. درخواست در چت تشخیص داده می‌شود.

## چه چیزهایی اجرا شده
- موتور برنامه‌ریز ۵۲ حرکت در گروه‌های `fun / persian / pop / smooth / energetic` که طرح قطعه‌ها را با ریتم 4/4 یا 6/8 و زمان ۶۰ یا ۱۲۰ ثانیه آماده می‌کند.
- تصاویر اصلی، صفحات استوری‌بورد و نماهای چندزاویه در `references/arina/` حفظ شده‌اند و فقط برای مرجع بصری و سناریوی رندر استفاده می‌شوند؛ هیچ اسلایدشو از کراپ تصاویر به اسم ویدیو عرضه نمی‌شود.
- چهار قطعه صوتی کوتاه **اورجینال و بی‌کلام** برای دمو در `public/arina-live/assets/audio` وجود دارد؛ آهنگ‌های معروف/ترند به علت نبود مجوز پخش در بسته نیستند. پس از لمس دکمه پخش، آهنگ متناسب با صحنه انتخاب می‌شود و هنگام رقص بلندتر و هنگام خواندن/نوشتن چت ملایم‌تر می‌شود.
- اگر ویدیوی MP4 واقعی و تأییدشده بارگذاری شود، همان کلیپ برای همه بازدیدکننده‌ها با زمان سرور پخش می‌شود؛ نسخه فعلی **هیچ فیلم کاملِ AI تولیدشده‌ای ندارد**.
- برای گروه‌بندی کلیپ‌ها، اسکریپت FFmpeg موجود است، اما کیفیت گذار فقط پس از بررسی انسانی قابل قبول است.

## تولید ویدیوی واقعی آرینا (برخلاف وصل‌کردن عکس‌ها)
1. در ComfyUI از **Wan2.2 Animate** (حالت Move) استفاده کن. ورودی: عکس ثابت مرجع آرینا؛ ویدیوی واقعیِ نمونه رقص دارای حق استفاده؛ کنترل بدن/صورت با DWPose؛ برای کیفیت بهتر از مدل بزرگ‌تر و GPU مناسب استفاده کن.
2. برای هر ۶ تا ۱۰ ثانیه، یک کلیپ متحرک بساز: عکس مرجع ثابت، شناسایی چهره و مدل لباس یکسان؛ دوربین ثابت و زاویه بدون زوم؛ نور و پس‌زمینه یکسان. حتماً انتهای هر کلیپ در ژستی تمام شود که ابتدای بعدی از همان ژست آغاز می‌شود.
3. طبق `render-jobs/` از مدل بخواه بازوها، مو، لباس و دست‌ها بدون فلیکر، اعوجاج و پرش باشند. کلیپ را در 1920x1080/30fps خروجی بگیر یا اگر مدل پایین‌تر ساخته، **فقط Upscale واقعی مناسب** انجام بده؛ تغییر ساده عدد رزولوشن به معنی تولید جزئیات Full HD نیست.
4. در ابتدای رقص و انتهای آن حالت نشستن/ایستادن همسان با نمای معمولی را رندر کن. کلیپ‌های کوتاه را با همان ژست به هم متصل کن. «xfade» به‌تنهایی خطای حرکت و تغییر لباس یا زاویه را تعمیر نمی‌کند.
5. برای ساخت ۶۰ تا ۱۲۰ ثانیه و ترکیب بخش‌های مختلف، manifest از کلیپ‌های **واقعی** بده:

```json
{
  "crossfadeSeconds": 0.5,
  "clips": [
    { "path": "/absolute/path/dance-A.mp4", "reviewed": true, "fixedCamera": true, "allowedToUse": true, "entryPose": "center", "exitPose": "center" },
    { "path": "/absolute/path/dance-B.mp4", "reviewed": true, "fixedCamera": true, "allowedToUse": true, "entryPose": "center", "exitPose": "center" }
  ]
}
```

این فقط نمونه دوکلیپی است؛ برای خروجی یک تا دو دقیقه باید فایل‌های بیشتری تهیه و مجموع مدت را به ۶۰ یا ۱۲۰ ثانیه برسانی. بررسی ژست، رضایت و حق استفاده از هر کلیپ ضروری است.

```bash
node scripts/arina-generate-plan.mjs 'آرینا رقص فان دو دقیقه'
node scripts/arina-video-pipeline.mjs inspect --input /absolute/path/full-dance.mp4
node scripts/arina-video-pipeline.mjs assemble --manifest /absolute/path/clips.json --output /absolute/path/full-dance.mp4
node scripts/arina-video-pipeline.mjs publish --input /absolute/path/full-dance.mp4 --motion dance-fun --reviewed
```

پس از انتشار، سرور Node.js را ری‌استارت کن تا فهرست ویدیوها را بخواند. CLI برای فایل 1920×1080، فریم‌ریت ≥24 و مدت ۶۰ تا ۱۲۰ ثانیه اعتبارسنجی دارد؛ اما وارسی چهره، هم‌خوانی ژست/دوربین و نبود تغییر ناگهانیِ بدن هنوز به تأیید انسانی نیاز دارد. فایل‌ها فقط از مسیر `public/arina-live/assets/video` سرو می‌شوند.

## وضعیت فعلی دقیق

| بخش | نتیجه |
|---|---|
| ۵۲ طرح حرکت | تعریف و تست کد |
| ۶۰/۱۲۰ ثانیه توالی موزون | برنامه‌ریزی و تست کد، بدون کلیپ واقعی |
| پخش ویدیوی واقعی تأییدشده | پشتیبانی سرور و مرورگر |
| استریم همزمان همه بازدیدکننده‌ها | اشتراک صحنه، حضور و چت با SSE (تک‌پردازش) |
| GPU + تولید ویدیوی آرینا | نصب/اجرا نشده |
| کیفیت سینمایی واقعی 1080p | تأیید نشده؛ تنها با کلیپ واقعی قابل آزمایش است |
| موسیقی ایرانی/ترند دارای کپی‌رایت | داخل بسته نیست؛ برای انتشار نیازمند فایل مجاز |
| فعالیت ۲۴ ساعته | نیازمند هاست پایدار و نظارت سرور |

**محدودیت هاست:** مدل‌های بزرگ Wan روی cPanel اشتراکی قابل اجرا نیستند. آن‌ها را روی GPU کامپیوتر/Worker رندر کن و MP4های تأییدشده را برای پخش روی هاست Node.js قرار بده. برای چند سرور همزمان نیاز است جلسات و state مشترک در Redis یا پایگاه داده توزیع شود.
