# فضی استودیو — مرکز عمومی پلاگین‌ها / FEZI Studio Public Plugin Directory

## بعد از انتشار وب‌سایت چه چیزی فعال می‌شود؟
- مسیر عمومی `/plugins` بدون ورود و رمز قابل مشاهده است؛ تمام ۹ پلاگینِ شناخته‌شده در صفحه معرفی می‌شوند.
- مسیر read-only `GET /api/plugins/public` فهرست معرفی را از `public/plugins/registry.json` می‌خواند.
- همه ۹ پلاگینِ ChatGPT هنگام ساخت بسته **خصوصی** بودند (`discoverability: PRIVATE`). این سایت نمی‌تواند صرفاً با آنلاین‌شدن، سطح دسترسی آن پلاگین‌ها را به PUBLIC تغییر دهد. در نتیجه دکمه ChatGPT آنها تا انتشار رسمی/تأیید دسترسی غیرفعال است.
- دکمه «بازکردن ابزار مرتبط در سایت» به بخش مرتبط از *همین* وب‌سایت می‌رود؛ الزاماً همه قابلیت‌های پلاگین ChatGPT را ندارد.
- هیچ API، کلید و اطلاعات خصوصی سرویس‌دهنده در رجیستری عمومی انتشار نیافته است.

## مراحل نصب
۱) برای پروژه فعلی از ZIP کامل استفاده کنید، یا فایل‌های ZIP پچ را روی سورس موجود اعمال کنید.
۲) `npm test` (یا `node --test tests/public-plugin-directory.test.js`) را اجرا کنید.
۳) پروژه را با `npm start` روی هاست دارای Node 22 راه‌اندازی کنید.
۴) در مرورگر `/plugins` و `/api/plugins/public` را از دامنه عمومی بررسی کنید.
۵) وضعیت PRIVATE پلاگین‌های ChatGPT را از طریق ابزار رسمی انتشار ChatGPT جداگانه تغییر دهید (در صورت امکان و با مجوز حساب). تنها **بعد از تأیید عمومی‌شدن واقعی** در `public/plugins/registry.json` برای همان مورد `chatgpt.access` را `public` و `chatgpt.publicReady` را `true` قرار دهید؛ سپس انتشار وب‌سایت را انجام دهید.

## محدودیت
انتشار وب‌سایت، پلاگین ChatGPT را نصب، فهرست عمومی، یا دارای دسترسی Read/Write نمی‌کند. در هنگام انتشار فقط کاتالوگ عمومی و مسیرهای موجود وب‌سایت فعال می‌شوند.

## فایل‌های ویرایش‌شده
- `server.js` برای مسیرهای whitelist عمومی
- `public/fezi-hub/home.html` لینک دعوت در بدنه صفحه اصلی
- `public/landing/index.html` لینک در بخش محتوا (نه هدر)
- `public/plugins/index.html`, `style.css`, `app.js`, `registry.json`
- `tests/public-plugin-directory.test.js`
