## قواعد ادامهٔ کار
- از تصویر اصلی آرینا استفاده شود؛ چهره با شخصیت تازه جایگزین نشود.
- هویت بصری: موهای موج‌دار قهوه‌ای، هدفون صورتی گوش‌گربه‌ای، فضای گیمینگ صورتی/بنفش.
- دوربین استریم ثابت و قاب ویدیو 16:9 باشد.
- برای حلقه‌ها همان تصویر مرجع به‌عنوان فریم اول و آخر استفاده شود. تعیین مرجع یکسان به‌تنهایی تطابق پیکسلی خروجی مدل را تضمین نمی‌کند؛ خروجی باید بررسی شود.
- حرکت‌ها: نگاه به چت، تایپ، لبخند، واکنش شاد و بازگشت طبیعی به حالت شروع.
- فعلاً گفتار صوتی اضافه نشود؛ صدای کیبورد فقط هنگام تایپ.
- پیش از دستور صریح ساخت، فقط اطلاعات و سناریو جمع‌آوری شود.
