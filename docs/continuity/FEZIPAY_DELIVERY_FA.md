# تحویل FeziPay و Announcement — ۲۰۲۶-۱۱-۰۴

## آنچه ساخته و آزمایش شده
- صفحه `/fezipay/` با دو تصویر ارسالی، خدمات، تماس‌ها، شرایط تسویه، محاسبه نمونه کارمزد ۱۵٪، ۲۲ ردیف کیف پول و ابزار ساخت HTML سفارشی.
- نسخه مستقل استاتیک مناسب GitHub Pages؛ دامنه هنوز خریداری یا متصل نشده است.
- پنل `/fezipay/announcement.html`: ورود مدیر با رمز موجود سایت، افزودن API Key Secret، ثبت گروه یا کانال دارای مجوز، پیش‌نمایش و تأیید ارسال.
- ربات مرکزی: `/broadcast متن`، `/confirm شناسه`، `/status`؛ کاربران `/subscribe` و `/unsubscribe` دارند. ارسال محدود به مقصدهای مجاز ثبت‌شده است. اشتراک صرفاً با عضویت در ربات فرض نمی‌شود.
- توکن‌ها AES-256-GCM روی سرور؛ SQLite پایدار؛ جلوگیری از ارسال تکراری به مقصد مشترک، رعایت فاصله ۳٫۱ ثانیه، رسیدگی به 429 و 403. نتیجه مبهم شبکه بدون بررسی دوباره ارسال نمی‌شود. امکان تضمین دقیقاً یک‌بار در Telegram وجود ندارد.
- ۱۳ توکن از ۱۴ توکن با getMe اعتبارسنجی و در پایگاه خصوصی رمزگذاری شدند. ربات Announcement معتبر بود. توکن با برچسب «telgram bot 8» تأیید نشد؛ علت قطعی مشخص نیست. هیچ پیام عمومی یا خصوصی ارسال نشده است.
- هسته دفتر مالی: فقط پس از verifier مستقل، ثبت رخداد غیرقابل‌ویرایش، عدم ثبت دوباره، محاسبه بر مبنای واحد صحیح، کسر کارمزد و رزرو اتمیک برداشت. اعلان مالی در outbox ذخیره می‌شود؛ ارسال واقعی اعلان هنوز متصل نیست.
- ۲۸ تست موفق و بررسی ۷ مسیر وب و ممنوعیت دسترسی بدون ورود به API مدیر.

## تنظیم ربات‌ها
Node.js 22.13+ یا 24 لازم است. فایل خصوصی را فقط روی سرور خارج از GitHub نگه دارید. `ANNOUNCEMENT_MASTER_KEY` و دیتابیس باید با هم حفظ شوند؛ گم‌شدن کلید بازیابی توکن رمز‌شده را ناممکن می‌کند.
`ANNOUNCEMENT_BOT_ID` مشخص شده، ولی `ANNOUNCEMENT_ADMIN_IDS` باید با شناسه عددی تلگرام مالک پر شود؛ نام کاربری جای آن نیست. سپس متغیرها را در هاست برای سایت و worker یکسان تنظیم کنید و `npm run announcement:worker` را در process manager دائمی اجرا کنید. فقط یک worker مرکزی اجرا کنید.
سه ربات موجود Studio، Arina و Login به فرمان عضویت وصل شده‌اند؛ برای ربات‌های خارجی تابع `announcementSubscription` در مصرف‌کننده موجود update قرار گیرد. از راه‌اندازی polling دوم یا حذف webhook ربات خارجی خودداری کنید. افزودن توکن به‌تنهایی مخاطبان تاریخی آن ربات را بازیابی نمی‌کند.
گروه/کانال از پنل مدیر با اجازه مالک ثبت شود؛ ربات کانال باید اجازه ارسال داشته باشد. برای کاربران خصوصی، خود کاربر `/subscribe` می‌فرستد. لغو عضویت روی هر ربات جداست.
کلید جدید فقط از پنل HTTPS وارد شود. کلید در چت Announcement ارسال نشود. پنل هنوز رابط حذف کامل یا بازبینی صف مبهم ندارد؛ API غیرفعال‌سازی ربات و لغو مقصد موجود است.

## مسیر مالی هنوز عملیاتی نیست
verifier بلاکچین، قراردادهای دقیق توکن، تأیید مالکیت آدرس‌ها، پنل واقعی مشتری، احراز هویت امن، امضای پرداخت خروجی، بازپرداخت، مدیریت اختلاف و worker اعلان مالی هنوز باید پیاده و یکپارچه شوند. هسته دفتر مالی به مسیر عمومی پرداخت وصل نشده و نباید موجودی آزمایشی را پول واقعی دانست. هیچ وجهی دریافت یا تسویه نشده است.
به‌ویژه Base، Artibitrum و Polygon نام شبکه‌اند و دارایی دقیق معلوم نیست؛ وضعیت تگ XRP باید تعیین شود. آدرس‌ها عیناً حفظ شده‌اند، اما صحت انتقال تضمین نشده است.
اطلاعات قانونی بهره‌بردار، مجوزهای لازم، سقف‌ها، مسیر رسمی استعلام اینماد و روش نگهداری مدارک احراز هویت هنوز لازم است. عکس چهره و کانال یوتیوب جایگزین این موارد نیستند.
