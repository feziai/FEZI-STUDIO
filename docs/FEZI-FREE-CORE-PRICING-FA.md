# سیاست هزینه‌های FEZI Studio v1.01

- استفاده از FEZI Studio و FEZI Agent برای کاربران **رایگان** است: ساخت وب‌سایت/اپلیکیشن/کد، بخش‌های تصویر و ویدیو و ابزارها. محدودیت مصرف منصفانه و شرایط در دسترس بودن مدل‌های رایگان ممکن است وجود داشته باشد.
- **خدمات اختصاصی و هدیه‌های آرینا**، اگر توسط کاربر انتخاب شوند، بخش پولی دارند.
- **فروش API Key و شارژ اعتبار API** بخش پولی مستقل از استفاده عمومی FEZI است؛ چون مصرف آن برای اپراتور هزینه ایجاد می‌کند.
- مدل پولی نباید به‌صورت پیش‌فرض یا بدون سقف بودجه در مسیر FEZI Agent رایگان مصرف شود. انتخاب‌گر رایگان باید مدل‌های واقعاً رایگان را ترجیح دهد و در صورت نبود منابع، وضعیت عدم دسترسی نشان دهد؛ نه نتیجه ساختگی یا بدهی بی‌حد.
- بازارچه، در صورت باقی‌ماندن در کد برای سابقه، نباید به‌عنوان paywall برای ابزارهای اصلی FEZI فعال شود. هزینه گرفتن برای امکانات عمومی نیازمند تصمیم تازه مالک است.
- پرداخت واقعی و صدور خدمات مبتنی بر تأیید تسویه باید تا هنگام تکمیل پردازشگر پرداخت غیرفعال بماند.
- این فایل حاوی هیچ کلید محرمانه‌ای نیست.
