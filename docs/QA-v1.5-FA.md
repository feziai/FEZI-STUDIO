## محدودیت‌های نسخه و موارد نیازمند اتصال واقعی

1. **خود GitHub هاست Node.js دائمی نیست.** workflow قبلی GitHub Actions → SSH cPanel حفظ شده؛ نیازمند فعال بودن SSH، استقرار ایمن و پشتیبانی سرویس Node.js در هاست.
2. مدل‌های ذکرشده در کاتالوگ هنوز نصب نشده‌اند. نیازمند بررسی مجوز، GPU یا provider، تأیید هزینه و اتصال worker هستند.
3. ورودی عکس/تصویر مرجع برای موتور ویدیو فقط در UI به اندازه مستند مدل نشان داده می‌شود؛ انتقال فایل چندتصویری به GPU فعلاً انجام نمی‌شود.
4. حساب عمومی شامل ثبت‌نام ایمیل/رمز و آپلود عکس پروفایل است. تأیید ایمیل، بازیابی رمز و Google OAuth هنوز پیاده‌سازی نشده.
5. دریافت ارز دیجیتال هنوز هیچ افزایش اعتبار خودکار ندارد؛ ارسال دستی ارز بدون تراکنش و تأیید زنجیره، اعتبار ایجاد نمی‌کند.
6. آثار آپلودی فقط با **رضایت انتشار و تأیید مدیر** عمومی می‌شوند؛ بررسی محتوای تصویری خودکار و در مقیاس بالا هنوز نیازمند سرویس ویژه است.
7. قابلیت‌های قدیمی سازنده `/builder` مدیرمحور باقی مانده و **به کاربران عمومی دسترسی مالک پروژه‌ها داده نشده**؛ این جداسازی موقت عمدی و امنیتی است.
8. اتاق خصوصی آرینا به‌صورت صریح **آواتار AI** شناسانده می‌شود و استفاده جنسی غیررضایتمندانه از چهره واقعی افراد یا جعل هویت مجاز نیست. صرف تیک ۱۸+ تأیید سن معتبر نیست.
9. انگلیسی زبان پیش‌فرض صفحات جدید است؛ ترجمه فارسی در بخش‌های قدیمی یکسان‌سازی کامل نشده. لینک Google Translate وابسته به خود Google و دسترسی شبکه است.
10. ربات عمومی برای اجرا به پروسه مستمر یا cron cPanel، توکن معتبر و URL عمومی HTTPS نیاز دارد؛ تست تماس واقعی Telegram صورت نگرفته.
