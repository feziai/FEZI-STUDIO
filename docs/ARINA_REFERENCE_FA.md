# مرجع جدید آرینا — FEZI AGENT v0.77

تصویر جدید آرینا `public/brand/arina.png` است؛ با موهای قهوه‌ای تیره موج‌دار، چتری، هدفون صورتی گوش‌گربه‌ای، لباس صورتی و اتاق گیمینگ صورتی-بنفش. این تصویر در `/showcase` و `/avatar?model=arina` پیش‌فرض است.

تم اصلی وب‌سایت آبی و سفید باقی مانده و لوگوی F حفظ شده است. صفحه `/` همچنان محیط برنامه‌نویسی است. `/showcase` صفحه معرفی چندمنظوره و `/avatar` ابزار آواتار است.

حرکت عکس در صفحه معرفی افکت CSS است و آزمایش صدا از قابلیت گفتار دستگاه استفاده می‌کند؛ این‌ها رندر فوتورئال یا ویدیوی زنده GPU نیستند.

برای اجرای واقعی مدل GPU و صحبت طبیعی به موتور تصویری و گفتار سازگار نیاز است. سایر تصاویر فقط برای نمایش کارت مدل‌های پیش‌فرض استفاده شده‌اند.
