# بررسی قبل از انتشار FEZI Plugin Hub

- [ ] مخزن GitHub خصوصی است
- [ ] هیچ API Key، توکن، دادهٔ شخصی یا فایل .env واقعی در مخزن نیست
- [ ] تست‌های Node.js در GitHub Actions سبز هستند
- [ ] هاست Node.js 22 و HTTPS راه‌اندازی شده
- [ ] FEZI_PLUGIN_HUB_TOKEN روی سرور با ۳۲+ کاراکتر تصادفی تنظیم شده
- [ ] برای هر پلاگین، Source Export جاری جداگانه تأیید شده
- [ ] برای هر upstream، ابزارهای عملیاتی با درخواست واقعی تست شده‌اند
- [ ] نصب/اشتراک پلاگین ChatGPT با مجوز کاربر انجام شده
- [ ] برای استفادهٔ عمومی OAuth/OIDC و مجوزهای کاربرمحور افزوده شده

**GitHub Actions فقط کد را تست می‌کند؛ فعال‌سازی MCP در هاست و ارائهٔ دسترسی ChatGPT مراحل جدا هستند.**
