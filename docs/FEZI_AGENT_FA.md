# راهنمای FEZI AGENT نسخه ۱.۰

## برند

نام قابل نمایش محصول و دستیار: **FEZI AGENT**. پنل عمومی برای انتخاب مدل یا ارائه‌دهنده وجود ندارد. نام‌ها و مشخصات فنی ارائه‌دهنده‌ها برای کاربر عادی ارسال نمی‌شوند؛ با این حال فایل‌های سورس، لاگ داخلی مدیر، وابستگی‌های فنی و اطلاعیه‌های مجوز همچنان واقعی و قابل بررسی‌اند. اگر کسی دربارهٔ منشأ یا نحوه عملکرد سیستم مستقیماً سؤال کند، پاسخ باید صادقانه باشد.

## انتخاب خودکار مدل

1. درخواست فارسی یا انگلیسی در سرور به دسته‌ای مانند برنامه‌نویسی، ترجمه، استدلال، تصویر، ویدیو یا عمومی طبقه‌بندی می‌شود.
2. فقط مدل GGUF نصب‌شده، مدل‌های گزارش‌شده توسط سرویس محلی در دسترس و ارائه‌دهنده‌هایی که مدیر API آن‌ها را در سرور تنظیم کرده است کاندید می‌شوند.
3. `FEZI_ROUTING_PREFERENCE=local-first` استفاده از گزینه‌های محلی را ترجیح می‌دهد؛ `quality-first` ممکن است ابتدا به API خارجی وصل شود. امتیازدهی ابتدایی است و بهترین بودن مدل را اثبات نمی‌کند.
4. برای پیشنهاد ویرایش کد، در صورت شکست اولیه تا سه گزینه جایگزین دیگر امتحان می‌شوند. برای عامل چندمرحله‌ای هم مکانیزم جایگزین فعال می‌شود.
5. اگر هیچ مدل فعال نباشد، FEZI AGENT خطای صریح «نیازمند اتصال یا نصب موتور» نشان می‌دهد و پاسخ ساختگی تولید نمی‌کند.

## راه‌اندازی

```bash
cp .env.example .env
# رمزهای اختصاصی APP_PASSWORD و SESSION_SECRET را تنظیم کنید.
# برای مدل محلی LOCAL_AI_ENABLED و نصب مدل مطابق راهنمای قبلی است.
node --env-file=.env server.js
```

آدرس `http://127.0.0.1:3000` را باز کنید. برای استقرار عمومی از HTTPS، احراز هویت قوی و جداسازی کاربر/مدیر استفاده کنید. سرور MCP فعلاً توسعه‌ای است و پلاگین عمومی ChatGPT ثبت نشده است. مدل‌های تجاری، وزن مدل‌های شخص ثالث و اجزای سنگین روی هاست cPanel به‌صورت خودکار نصب نمی‌شوند.

## تفاوت رابط عمومی و اطلاعات فنی

- کاربر عادی: تنها FEZI AGENT، دریافت خروجی، و وضعیت تسک.
- مدیر توسعه: کدهای اتصال، سوابق خطای موتور و مجوزها جهت رفع خطا و رعایت شرایط استفاده.
- کد تولیدشده: نام کتابخانه‌های لازم، مجوزها، وابستگی‌ها و importهای فنی حفظ می‌شوند تا برنامه واقعاً قابل اجرا باشد.

## تست

`npm test` برای تست‌های موجود و جدید. تست اتصال به مدل‌های واقعی و پلاگین عمومی پس از استقرار باید جداگانه انجام شود.
