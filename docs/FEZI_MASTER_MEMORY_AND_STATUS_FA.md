# حافظهٔ مرجع پروژه FEZI Studio — ۸ نوامبر ۲۰۲۶

این فایل خلاصهٔ پایدار پروژه در داخل سورس است؛ **به معنی ذخیره‌شدن در Memory حساب ChatGPT نیست.**

## هویت و ماهیت
- نام: **FEZI Studio — فضی استودیو**.
- یک وب‌سایت Node.js 22 با همه ابزارها در یک پروژه و دامنه.
- هدر سایت، لوگوی تاییدشده خرگوش-F و امکانات موجود نباید بی‌دلیل تغییر یا حذف شوند.
- **مأموریت اول FEZI Agent: ساخت، ویرایش، نصب، تست و انتشار وب‌سایت و وب‌اپ**.

## اولویت عملیاتی
۱. FEZI Agent: ساخت وب‌سایت و مدیریت سورس + آزمون end-to-end
۲. مخزن GitHub با اتصال دارای مجوز نوشتن، branch/PR و انتشار قابل بازگشت
۳. کتابخانه اسکیل‌های معتبر موجود، MCP احراز هویت‌شده، Shell محدود و قابل ممیزی
۴. Telegram Bots: BotFather، منو، فرمان، خروجی پروژه، grammY / Telegraf / aiogram / Node
۵. OpenRouter با مدل‌های رایگان، Hugging Face و GitHub برای کشف مدل، بدون ادعای اجرای مدل تست‌نشده
۶. زمان‌بندی اکتشاف روزانه، آزمون و گزارش، انتشار medium فقط پس از Staging و مجوز از پیش تعریف‌شده
۷. چارچوب‌های Transformers، smolagents، LangChain، LiteLLM، Flowise، n8n، Open WebUI با بررسی مجوز

## وضعیت
- سورس و برخی تست‌های محلی موجود است؛ «READY» در گزارش ایستا فقط به معنی آماده‌بودن فایل‌هاست.
- اتصالات واقعی ChatGPT Plugin، Telegram، GitHub Push، API مدل‌ها و HTTPS باید جداگانه در سرور بررسی شوند.
- GPU برای شروع API-first اجباری نیست.
- فایل `Dotenv.txt` کاربر حاوی اسرار است: **کلیدهای به‌اشتراک‌گذاشته‌شده باید تعویض شوند** و هرگز به مخزن عمومی نروند.
- حفظ نام و ماهیت هر زیرسیستم الزامی است؛ قابلیت‌های جدید با آزمون واقعی اضافه شوند.

## حافظه ChatGPT
Memory حساب ممکن است به‌صورت خودکار از گفتگوهای گذشته خلاصه بسازد و ثبت آن از طریق این فایل تضمین نمی‌شود. برای بازبینی و اصلاح، Settings → Personalization → Memory summary → Manage را باز کنید.
