# فضی استودیو — Telegram Plugin Builder در Plugin Hub

## چه چیزی اضافه شده؟
- آدرس عمومی سازنده: `/plugins/telegram-builder`
- کارت سازنده در `/plugins` (هدر قبلی وب‌سایت تغییر نکرده است)
- تعریف دستورها و پاسخ‌ها، دکمه لینک وب‌سایت، پیش‌نمایش و صادرکردن ZIP اجرایی
- خروجی ZIP شامل `bot.mjs`, `plugin.json`, `package.json`, `README_FA.md`, `.gitignore`, `.env.example` است. هیچ توکن واقعی در خروجی نیست.
- هاست کردن ربات روی سرور فضی استودیو تنها برای مدیر واردشده (cookie نشست `bg_session`) ممکن است.
- توکن BotFather با AES-256-GCM در فضای داده سرور ذخیره می‌شود و در API به مرورگر برگردانده نمی‌شود.
- دریافت Webhook تلگرام با هدر محرمانه `X-Telegram-Bot-Api-Secret-Token` اعتبارسنجی می‌شود.
- تنها پیام خصوصی و پاسخ به دستور اجرا می‌شود؛ بدون ارسال پیام تبلیغاتی انبوه یا اجرای آزاد کد روی سرور.

## نصب روی سورس FEZI Studio
فایل‌های ZIP پچ را در ریشه پروژهٔ فعلی جایگزین کنید. نیازی به نصب پکیج npm اضافی نیست. با Node.js 22 اجرا می‌شود.

```bash
node --test tests/telegram-plugin-hub.test.mjs
node --check server.js
npm start
```

## راه‌اندازی روی دامنه واقعی
در سرور پشت HTTPS با دامنه واقعی:

```
APP_PASSWORD=YOUR_STRONG_OWNER_PASSWORD
SESSION_SECRET=LONG_UNIQUE_RANDOM_SECRET_AT_LEAST_24_CHARS
PUBLIC_BASE_URL=https://YOUR-ACTUAL-DOMAIN
DATA_DIR=/persistent/storage/fezi
```

**مهم:** `PUBLIC_BASE_URL` باید دامنه HTTPS در دسترس از اینترنت باشد. پیش از استقرار یا در `localhost`، اتصال Webhook غیرفعال می‌ماند. فضای `DATA_DIR` باید پایدار و محافظت‌شده باشد. با تغییر SESSION_SECRET، اطلاعات توکن‌های ذخیره‌شده قابل رمزگشایی نخواهند بود مگر کلید قبلی را نگه‌داری کنید.

1. در Plugin Hub روی «ساخت پلاگین تلگرام» کلیک کنید.
2. از یکی از قالب‌ها شروع کنید؛ دستورهای سفارشی را بنویسید و پیش‌نمایش بگیرید.
3. برای هر کاربر عمومی گزینهٔ «دانلود ZIP» سورس اجرایی می‌دهد. در VPS خودشان با توکن BotFather و `npm start` می‌توانند آن را راه‌اندازی کنند؛ سرور دائمی لازم است.
4. برای میزبانی روی سرور فضی استودیو، مدیر با `/api/login` احراز هویت کرده، توکن رباتی را که مالک است وارد می‌کند و «اتصال به تلگرام» را می‌زند.
5. پس از موفقیت واقعی `getMe`, `setWebhook` و `setMyCommands`, لینک `https://t.me/USERNAME` برمی‌گردد و پیام‌های کاربر تلگرام با Webhook پاسخ داده می‌شوند.
6. مدیر هر زمان می‌تواند از فهرست خود Bot را Disconnect کند؛ Webhook حذف می‌شود، ولی حساب ربات در تلگرام حذف نمی‌شود.

## محدودیت‌ها و امنیت
- این سازنده **ربات تلگرام واقعی** و گردش‌کار پاسخ دستور تولید می‌کند؛ افزونه داخلی برنامه Telegram یا افزونه ChatGPT نیست.
- ربات‌های سایت در سرور راه‌اندازی نشده‌اند مگر اینکه توکن معتبر، HTTPS، مجوز مدیر و پاسخ موفق API تلگرام وجود داشته باشد.
- برای ایجاد ربات جدید با BotFather باید مالک ربات خود شخصاً اقدام کند.
- ساخت ZIP عمومی است ولی میزبانی روی سرور فضی استودیو در این نسخه فقط به مدیر اصلی محدود شده است. برای میزبانی خودکار ربات‌های کاربران، باید مدیریت حساب و سهمیهٔ چندمستاجری امن توسعه داده شود.
- این نسخه فقط پاسخ‌های ثابت و تنظیم‌شده را اجرا می‌کند؛ قابلیت اجرای کد دلخواه، AI زنده، پرداخت و ارسال گروهی ندارد. چنین ابزارهایی به توسعه و احراز هویت جدا نیاز دارند.
- در Telegram نمی‌توان ربات را صرفاً با آپلود ZIP فعال کرد. اجرای Node.js دائمی یا میزبانی Webhook الزامی است.
- `getUpdates` در بسته دانلودی جایگزین Webhook است و با Webhook فعال همزمان کار نمی‌کند.
- پیش از انتشار توکن‌های قدیمی منتشرشده را تعویض کنید. توکن‌ها را داخل فایل، مخزن یا چت عمومی قرار ندهید.
