# ۱۰۰ سناریوی گفت‌وگو آرینا

این ۱۰۰ سناریو برای ارزیابی تشخیص درخواست و رفتار نمایشگر آماده شده‌اند؛ **آموزش یا Fine-tune واقعی مدل نیستند**. برخی ورودی‌ها برای سنجش توان گفت‌وگو عمومی هستند و خروجی حرکتی پیش‌فرض دارند. هیچ‌کدام تضمین نمی‌کنند مدل از این متن‌ها چیزی را یاد گرفته است.

برای آموزش شخصی‌سازی واقعی باید گفتگوهای رضایت‌مندانه و داده‌های آموزش جداگانه جمع‌آوری و به فرایند ML متصل شوند.
