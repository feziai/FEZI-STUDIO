# fezi-studio-bot — FEZI Studio v1.01

فرمان‌ها، راهنمای ساخت، عضویت داوطلبانه در پیام روزانه و اتصال به Mini App مستقل به عنوان فرآیند اجرا می‌شوند. اما چت AI و ساخت تصویر طبق معماری فعلی به پل FEZI یا Worker نیاز دارند؛ توکن Telegram به‌تنهایی LLM نمی‌سازد.

## اجرای مستقیم روی Node.js 22

1. این پوشه را به عنوان مخزن مستقل در GitHub قرار بده؛ **بدون فایل کلید محرمانه**.
2. فایل `.env.example` را راهنما قرار بده و مقدارها را در متغیرهای محیطی/Secrets تنظیم کن.
3. `npm start` را در یک فرآیند پایدار اجرا کن. Telegram long polling را برای هر token فقط در **یک نمونه** اجرا کن.
4. بات را با BotFather تنظیم کن. اگر Mini App نیاز است، دامنه HTTPS واقعی لازم است.

**وضعیت:** آماده آزمایش محلی؛ هیچ رباتی روی هاست واقعی در این بسته اجرا نشده، توکن‌های ارسال‌شده در چت نیز داخل فایل‌ها قرار ندارند.
