# fezi-arina-bot — FEZI Studio v1.01

چت شخصیت آرینا بدون راه‌اندازی وب‌سایت FEZI قابل اجرا است، مشروط به Telegram token و OpenRouter free model. لایو، آلبوم، هدیه و اتصال حساب نیازمند سرویس وبسایت هستند. پاسخ واقعی فقط بعد از استقرار و پیکربندی متصل می‌شود.

## اجرای مستقیم روی Node.js 22

1. این پوشه را به عنوان مخزن مستقل در GitHub قرار بده؛ **بدون فایل کلید محرمانه**.
2. فایل `.env.example` را راهنما قرار بده و مقدارها را در متغیرهای محیطی/Secrets تنظیم کن.
3. `npm start` را در یک فرآیند پایدار اجرا کن. Telegram long polling را برای هر token فقط در **یک نمونه** اجرا کن.
4. بات را با BotFather تنظیم کن. اگر Mini App نیاز است، دامنه HTTPS واقعی لازم است.

**وضعیت:** آماده آزمایش محلی؛ هیچ رباتی روی هاست واقعی در این بسته اجرا نشده، توکن‌های ارسال‌شده در چت نیز داخل فایل‌ها قرار ندارند.

## هماهنگی با لایو و کانال آرینا
- `npm start` ربات مستقل را با توکن خصوصی خودش اجرا می‌کند و منوی «تماشای آرینا» را روی همان `PUBLIC_BASE_URL/arina-live` می‌گذارد.
- `npm run channel` فقط پیش‌نمایش پیام کانال است. با `ARINA_CHANNEL_ID` و `ARINA_CHANNEL_PUBLISH_ALLOWED=true`، دستور `npm run channel -- --publish --pin` یک پیام قابل سنجاق به کانال مجاز ارسال می‌کند.
- این روش لینک به مینی‌اپ است و پخش ویدیو در تمام پیام‌های فید کانال نیست. برای استریم واقعی کانال نیاز به RTMP و سرور همیشه‌روشن است.
- اگر ربات قبلاً webhook دارد، worker به‌طور پیش‌فرض آن را حذف نمی‌کند.
