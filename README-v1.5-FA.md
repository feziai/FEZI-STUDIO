# FEZI Studio v1.5 — نسخه کامل ادغام‌شده روی v1.4

**این بسته پروژه مستقل جدید نیست.** مبنای آن تمام فایل‌های نسخه `FEZI_STUDIO_v1.4_MERGED_FULL` است. هیچ فایل قدیمی حذف نشده؛ هسته Agent، آکادمی تسک‌ها، ابزارها، FAQ، گالری/کیف پول آرینا، پچ‌ها، آزمون‌ها، تصاویر مرجع، خروجی‌ها و مسیرهای قدیمی محفوظ‌اند. برنامه با Node.js >=22 اجرا می‌شود.

## مدل‌ها

`config/studio-models-v15.json` شامل **۲۳۷ ورودی کاتالوگ یکتا** از `config/open-models.json` قبلی و دو فایل ارسالی `open-source-ai-lists.md` و `nsfw-open-source-50.md` به همراه چند نسخه مشخص و موتور آواتار است. این تعداد شامل ابزارهای کدنویسی، رابط‌ها، موتورهای اجرا و مدل‌هاست و به معنی ۲۳۷ مدل نصب‌شده یا قابلیت تولید واقعی نیست. ۵۸ ورودی از منابع مرتبط با مدل‌های بزرگسالان مشخص شده‌اند؛ کاتالوگ بزرگسال با انتخاب داوطلبانه و تأیید سن خوداظهاری دیده می‌شود. این علامت‌گذاری به معنی تأیید مجوز یا تضمین تولید محتوای NSFW نیست.

- انتخاب تصویر، ویدیو، متن، کدنویسی، صدا و آواتار از طبقه‌بندی‌ها.
- `imageInputs`, `durationOptionsSec` و قابلیت‌های ورود چند فریم فقط وقتی نسخه مدل مستند شده مقدار می‌گیرند. `null` یعنی **نامشخص**. هیچ مدت ۳/۵/۱۰ ثانیه یا عدد عکس برای مدل‌های تأییدنشده اختراع نشده است.
- مدل‌های جدید کاتالوگ **خودکار نصب نشده‌اند**. برای اتصال به موتور قبلی تنها IDهایی که هم در `config/open-models.json` قبلی هستند و هم در `STUDIO_ENABLED_MODELS` مجاز شده‌اند قابل درخواست خواهند بود.
- ورودی چندعکس در رابط مشخص می‌شود، اما ارسال باینری عکس به GPU Worker هنوز پیاده نشده و در UI صریحاً خطا می‌دهد؛ فایل بی‌اطلاع فرستاده نمی‌شود.
- استفاده از وزن‌های آزاد روی سرور شخصی ممکن است هزینه سخت‌افزار و برق داشته باشد؛ APIهای ابری رایگان یا نامحدود فرض نمی‌شوند.
- تولید عکس/ویدیو روی cPanel بدون GPU فقط با Worker مستقلِ نصب‌شده قابل اجراست؛ این بسته خود GPU تهیه نمی‌کند.

## هویت و شخصیت آرینا

لوگوی `public/brand/fezi-rabbit-f.png` **دقیقاً همان فایل اصلی ارسالی** است؛ تغییر پیکسل/رنگ/فرمت انجام نشده. عکس جدید آرینا در `public/brand/arina-landing-official.jpg` قرار دارد. سیستم آرینا همچنان AI Avatar است؛ لازم نیست نام مدل زیرساخت نمایش داده شود اما هویت مصنوعی از مخاطب پنهان نمی‌شود. قیمت برنامه‌ریزی‌شده اتاق خصوصی از ۳ به **۹ دلار** تغییر کرد؛ سرویس ویدیویی خصوصی و پرداخت واقعی همچنان غیرفعال‌اند تا زیرساخت و تأیید معتبر آماده شوند.

چهره افراد واقعی برای تبدیل هنری غیرصمیمی در چارچوب اجازه/حقوق قابل بررسی است؛ محتوای جنسی بدون رضایت، دیپ‌فیک صمیمی افراد واقعی و هر محتوای جنسی مرتبط با خردسالان مجاز نیست. صرف تیک ۱۸+ احراز سن واقعی محسوب نمی‌شود. پیش از راه‌اندازی عمومی بزرگسالان، بررسی هویت/سن معتبر، فیلتر تصویری خروجی و بررسی قوانین و ارائه‌دهنده پرداخت لازم است.

## پروفایل، عکس‌ها و پرداخت

- پروفایل در فایل خصوصی `DATA_DIR/studio-v15/state.json` با کلید مشتق‌شده `scrypt` و کوکی امضاشده ذخیره می‌شود. داده‌ها و رمزها را به GitHub نفرستید.
- عکس پروفایل شخصی با حداکثر ۳۲۰ KB و انتخاب شش آیکون در UI وجود دارد. **احراز ایمیل و Google OAuth هنوز متصل نیست.**
- ۲۲ رکورد کیف پول از `core/arina-wallets.json` موجود **مستقیم** خوانده می‌شوند. فایل اصلی و QRهای `public/arina-gallery/qr` تغییر داده نشده‌اند. کپی آدرس‌ها از فیلد اصلی انجام می‌شود.
- هیچ تراکنشی بر اساس اسکرین‌شات یا ادعای مرورگر تأیید نمی‌شود؛ فاکتور، شارژ و محتوای پولی نیازمند پردازشگر معتبر شبکه، شناسه پرداخت کاربر و تأییدیه است.
- محتوای تولید/آپلود شده به طور پیش‌فرض **خصوصی** می‌ماند. انتشار عمومی فقط با تأیید صریح حق نشر/رضایت مالک و تأیید مدیر ممکن است. جستجوی باز و دانلود روی محتوای تأییدنشده انجام نمی‌شود.
- دیتابیس JSON محلی برای تست/نصب تک‌پردازشی است؛ برای تولید چندکاربره گسترده، PostgreSQL، صف پردازش، ابزارهای ضد اسپم و moderation عکس/ویدیو لازم‌اند.

## ربات تلگرام عمومی

سرویس مدیر اصلی در `scripts/telegram-poll.mjs` و `telegram.js` بدون تغییر باقی است. حالت جدید در `scripts/telegram-public.mjs` است:

- `/start`, `/help`, `/lang fa|en`, `/chat <question>`, `/motivate on|off`, `/image`, `/video`, `/app`, `/telegram`
- زبان پیش‌فرض از Telegram `language_code`، و پیام‌های انگیزشی فقط برای مشترکانی که **صریحاً فعال کرده‌اند** (۹:۰۰ UTC)؛ عدم تکرار روزانه با نگه‌داشتن تاریخ آخرین ارسال.
- `/image`, `/video`, `/app` لینک HTTPS به سایت می‌فرستند؛ چت را می‌تواند با موتور واقعی از API داخلی انجام دهد.
- برای اجرای پیوسته `TELEGRAM_MODE=public-polling` و `npm run telegram:public` در یک سرویس همیشه‌روشن؛ یا روی cPanel یک cron روزانه برای `npm run telegram:daily`. این دو را بدون برنامه‌ریزی روی یک توکن همزمان با webhook قبلی اجرا نکنید.
- ربات با توکن تازه یا بعد از خاموش‌کردن حالت polling/webhook قبلی فعال شود. هیچ توکنی در پروژه وجود ندارد.

## نصب و انتشار به GitHub / cPanel

GitHub **مخزن کد و CI/CD** است و به‌خودی خود سرور دائمی Node.js نیست. این بسته `.github/workflows/deploy-cpanel.yml` از نسخه اصلی را حفظ می‌کند تا با `workflow_dispatch` کدهای مخزن را به هاست Node.js در cPanel بفرستد.

1. ZIP را در پوشه مخزن GitHub باز کنید؛ **محتوای داخل پوشه اصلی** را در ریشه مخزن قرار دهید تا `package.json` و `server.js` در ریشه باشند. ZIP را به عنوان یک فایل منفرد آپلود و اجرا نکنید.
2. `Settings → Secrets and variables → Actions` در GitHub: `CPANEL_HOST`, `CPANEL_USER`, `CPANEL_SSH_KEY`, `CPANEL_APP_DIR`, `CPANEL_KNOWN_HOSTS` و در صورت نیاز `CPANEL_PORT`. تنها از SSH اختصاصی و با مجوز محدود استفاده کنید.
3. در cPanel بخش **Setup Node.js App**، Node >=22، Application root همان مسیر، startup file=`server.js`، دامنه HTTPS، `PORT/HOST` سازگار با Passenger و envهای زیر. در Passenger عموماً نباید `PORT` ثابت و `HOST=127.0.0.1` اجباری باشد؛ مقادیر هاست را رعایت کنید.
4. متغیرهای اصلی: `APP_PASSWORD`, `SESSION_SECRET`, `DATA_DIR` (خارج از Git و پایدار), `COOKIE_SECURE=true`, `PUBLIC_BASE_URL=https://YOUR_DOMAIN`.
5. برای چت: سرویس Ollama واقعی `OLLAMA_BASE_URL` یا کلید API رسمی سازگار با لایسنس. برای GPU: `FEZI_GPU_WORKER_URL`, `FEZI_GPU_WORKER_TOKEN`, `STUDIO_ENABLED_MODELS` و بعد از آزمون `STUDIO_PUBLIC_GPU_ENABLED=true`.
6. برای ربات: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBAPP_URL=https://YOUR_DOMAIN`, `TELEGRAM_INTERNAL_TOKEN` (حداقل ۲۴ کاراکتر)، `TELEGRAM_MODE=public-polling` فقط اگر واقعاً پروسه bot اجرا می‌شود.
7. **Secrets را در چت یا در فایل‌های ZIP / GitHub commit نفرستید.** مقادیر واقعی فقط در GitHub Actions Secrets و cPanel Environment Variables ذخیره می‌شوند. API های پرداخت و Google OAuth تا اعتبارسنجی callback/وبهوک و تأیید قانونی متصل نشده‌اند.

### تست

`npm test` تست‌های قبلی و تست جدید `tests/studio-v15.test.js` را اجرا می‌کند. `npm start` سایت را در localhost فعال می‌کند. در محیط تست محلی می‌توانید مسیر `/health` را باز کنید. `docs/QA-v1.5-FA.md` گزارش جزئیات است.

### محدودیت‌های شفاف

- هنوز مدلی نصب یا GPU اجاره نشده و هیچ استریم/ویدیوی واقعی جدید تولید نشده است.
- هیچ اتصال OAuth، اعتبارسنجی پرداخت ارز دیجیتال، قرارداد میزبان مدل بزرگسال یا دسترسی واقعی Github خودکار از فایل ZIP به‌تنهایی ایجاد نمی‌شود.
- ابزارهای سازنده قدیمی، GitHub ادغام‌شده در آن و تسک‌های خصوصی **مدیریتی** باقی می‌مانند؛ حساب عمومی نباید به آنها دسترسی پیدا کند. مهاجرت ایمن چندمستاجریِ سازنده کامل (با جداسازی فایل‌ها، مجوزها و سهمیه) یک مرحله توسعه مستقل است.
- ثبت ایمیل بدون verify، کیف پول بدون processor و انتشار عمومی بدون moderation تصویری، برای عرضه تجاری گسترده کافی نیستند.
