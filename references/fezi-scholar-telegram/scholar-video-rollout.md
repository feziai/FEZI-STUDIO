Installed package means shared instructions only; there is no live model or academic provider automatically enabled.

- Video: locate user-authorized generation provider; request 5 seconds; poll tool; deliver real MP4; prefer MCP Apps player if deployed.

- Cross-plugin knowledge: authorized skill-bus exchange, per-plugin identity and safe read-only research defaults.
