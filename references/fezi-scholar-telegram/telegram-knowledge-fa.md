# پایگاه دانش تلگرام برای GPT سفارشی
**Telegram Knowledge Base | نسخه ۱.۰ | زبان: فارسی**

> **کاربرد:** بارگذاری در بخش Knowledge یک GPT سفارشی برای پاسخ‌گویی دقیق‌تر درباره تلگرام، آموزش کار با آن و طراحی راهکارهای مبتنی بر ربات.
>
> **محدودیت به‌روزرسانی:** این متن مرجع مفهومی است، نه منبع زنده. امکانات، محدودیت‌ها، قیمت‌ها، مقررات، مسیر منوها و سیاست‌های تلگرام ممکن است تغییر کنند. برای جزئیات حساس به زمان از مستندات رسمی استفاده شود. این فایل به‌خودی‌خود هیچ اتصال یا دسترسی به حساب تلگرام ایجاد نمی‌کند.

## ۱) تلگرام چیست؟
تلگرام (Telegram) یک پیام‌رسان چندسکویی با گفتگوهای خصوصی، گروه‌ها، کانال‌ها، تبادل فایل، تماس و امکانات ربات‌هاست. تلگرام علاوه بر کاربرد شخصی، برای اطلاع‌رسانی، پشتیبانی مشتری، مدیریت اجتماعات و ساخت سرویس‌های تعاملی استفاده می‌شود.

### مفاهیم کلیدی
- **گفتگوی خصوصی:** مکالمه بین حساب‌های کاربری.
- **گروه (Group):** فضای گفتگو و تعامل اعضا؛ مناسب اجتماع و پشتیبانی.
- **کانال (Channel):** انتشار محتوا با تمرکز بر مخاطبان یا دنبال‌کنندگان؛ مناسب اخبار و اطلاعیه.
- **مدیر (Administrator):** نقش دارای برخی اختیارات مدیریتی که مالک فضا تعیین می‌کند.
- **ربات (Bot):** حساب نرم‌افزاری که از طریق Bot API کار می‌کند و رفتار آن با برنامه‌نویسی تعریف می‌شود.
- **نام کاربری و لینک عمومی:** راه‌های پیدا کردن یک حساب، گروه، کانال یا ربات؛ همه فضاها الزاماً عمومی نیستند.
- **Telegram Premium و سایر خدمات تجاری:** قابلیت‌ها و شرایط آن‌ها ممکن است در گذر زمان تغییر کند.

## ۲) گروه در برابر کانال
| ویژگی | گروه | کانال |
|---|---|---|
| هدف اصلی | گفتگو و اجتماع | انتشار پیام و اطلاع‌رسانی |
| مشارکت مخاطبان | معمولاً تبادل پیام بین اعضا | انتشار عمدتاً توسط مدیران، با امکانات تعاملی وابسته به تنظیمات |
| سناریوی رایج | انجمن، پشتیبانی، تیم | خبرنامه، رسانه، اطلاعیه |
| مدیریت | قوانین، نقش‌ها، نظارت بر گفتگو | برنامه‌ریزی محتوا، مدیریت انتشار |

## ۳) ربات تلگرام و Bot API
**BotFather** ابزار رسمی ایجاد و مدیریت ربات‌های تلگرام است. در یک گردش کار معمول:
1. با BotFather ربات بسازید و توکن دریافت کنید.
2. توکن را **محرمانه** نگه دارید و در فایل‌های عمومی، پیام‌های معمولی یا پایگاه دانش GPT قرار ندهید.
3. برنامه سرور/سرویس خود را برای فراخوانی Telegram Bot API آماده کنید.
4. پیام‌ها و رویدادها را با یکی از دو روش `getUpdates` (polling) یا `setWebhook` (webhook) دریافت کنید.
5. پاسخ مناسب را با روش‌هایی نظیر `sendMessage` بفرستید.
6. خطاها، نرخ درخواست‌ها، دسترسی‌ها و امنیت داده‌ها را مدیریت کنید.

**نکات کاربردی:**
- ربات نمی‌تواند صرفاً به دلیل دانستن نام کاربری، به هر فردی پیام اولیه بفرستد؛ آغاز تعامل یا مجوز/زمینه دسترسی لازم است.
- دسترسی ربات به پیام‌های گروه به تنظیمات و نقش‌های آن (از جمله privacy mode) وابسته است.
- ربات، جانشین یک حساب شخصی نیست و سطح دسترسی‌های متفاوتی دارد.
- توکن افشاشده را از طریق ابزار رسمی مربوطه باطل/تجدید کنید.

**مراجع رسمی:**
- https://core.telegram.org/bots
- https://core.telegram.org/bots/api
- https://t.me/BotFather

## ۴) انواع API و مرزهای دسترسی
- **Bot API:** رابط HTTP برای مدیریت ربات‌های تلگرام؛ مناسب راهکارهای معمول خدماتی.
- **Telegram API / MTProto:** رابط‌های سطح پایین‌تر برای توسعه کلاینت‌ها و برخی کاربردهای پیشرفته؛ نیازمند بررسی قوانین و الزامات مربوطه.
- **Mini Apps (Web Apps):** تجربه وب در محیط تلگرام و در ارتباط با ربات‌ها، با الزامات خاص امنیت و احراز هویت.

مرجع رسمی توسعه‌دهندگان: https://core.telegram.org/

## ۵) امنیت و حریم خصوصی
- گفتگوهای معمولی تلگرام **به‌طور پیش‌فرض رمزگذاری سرتاسری (E2EE) ندارند**؛ تلگرام برای پیام‌های معمولی از معماری ابری استفاده می‌کند.
- **Secret Chat** برای گفتگوهای یک‌به‌یک، رمزگذاری سرتاسری ارائه می‌دهد؛ کاربرد و دسترسی آن متفاوت از چت ابری است.
- برای حفظ حساب، تأیید دومرحله‌ای، بررسی نشست‌های فعال، قفل برنامه و محدودکردن نمایش شماره تلفن را در تنظیمات امنیت/حریم خصوصی بررسی کنید.
- کد ورود، رمز دوم، توکن ربات و کلیدهای API را با دیگران به اشتراک نگذارید.
- نسبت به پیوندهای فیشینگ، ربات‌های جعلی، فایل‌های ناشناس و پیشنهادهای سرمایه‌گذاری یا هدایای مشکوک حساس باشید.
- قبل از ذخیره یا ارسال پیام‌های اشخاص به سرویس AI، مجوز، مبنای قانونی مناسب و حداقل‌سازی داده را در نظر بگیرید.

## ۶) مدیریت حرفه‌ای کانال و گروه
### کانال
- تعریف هدف، مخاطب هدف و لحن محتوا
- ساخت تقویم انتشار و طبقه‌بندی موضوعی مطالب
- آماده‌سازی قالب پیام: تیتر روشن، متن کوتاه، فراخوان اقدام
- ثبت شاخص‌های متناسب (مثلاً بازدید یا تعامل در صورت دسترسی به داده معتبر)
- پرهیز از انتشار محتوای تکراری و ادعاهای بی‌منبع

### گروه
- تدوین قوانین رفتار و سیاست حذف محتوا
- تعیین نقش مدیران و مجوزهای دقیق
- مدیریت هرزنامه و گزارش‌های کاربران
- استفاده از ربات‌های مدیریتی قابل اعتماد، با حداقل دسترسی لازم
- رعایت حریم خصوصی اعضا و سیاست نگهداری اطلاعات

## ۷) اتصال تلگرام به یک GPT سفارشی
**محدودیت مهم:** قرار دادن این فایل در Knowledge به‌تنهایی GPT را به تلگرام وصل نمی‌کند. GPT سفارشی به صورت خودکار نمی‌تواند پیام‌های خصوصی، اعضای گروه، کانال‌ها یا توکن‌های تلگرام را بخواند.

### معماری نمونه برای ارسال محتوا از GPT به تلگرام
`کاربر در ChatGPT → GPT سفارشی → Action با API واسط امن → سرور شما → Telegram Bot API → چت/کانال مجاز`

پیش‌نیازها:
1. ربات در BotFather و مجوز لازم برای مقصد.
2. API واسط امن روی HTTPS.
3. تنظیم Action در GPT با OpenAPI schema و روش احراز هویت مناسب.
4. نگهداری امن توکن تلگرام **در سمت سرور**، نه در Instructions یا Knowledge.
5. کنترل مجوز انتشار و تأیید کاربر برای عملیات حساس.
6. آزمون ارسال پیام، خطاها، محدودیت‌های نرخ و گزارش‌گیری.

### معماری نمونه برای پرسش از تلگرام با AI
`پیام واردشده به ربات → webhook سرور → کنترل مجوز و پالایش داده → مدل AI → پاسخ از طریق Bot API`

این مدل الزاماً به معنای استفاده از همان GPT سفارشی داخل ChatGPT نیست؛ برای سرور معمولاً از یک API مدل هوش مصنوعی مجزا استفاده می‌شود. داشتن یک GPT سفارشی به‌تنهایی API مستقلی برای اجرای همان GPT در ربات تلگرام ایجاد نمی‌کند.

## ۸) کاربردهای پیشنهادی
1. تولید و ویرایش پست‌های کانال تلگرام.
2. ایده‌پردازی تقویم محتوایی هفتگی یا ماهانه.
3. تدوین قوانین گروه و متن خوشامدگویی.
4. طراحی جریان پاسخ‌گویی ربات پشتیبانی.
5. تحلیل داده‌های آماری کانال **در صورت ارائه داده معتبر توسط کاربر**.
6. تعریف سناریوهای اعلان، یادآوری و انتشار محتوا با تأیید کاربر.
7. بازبینی متن پیام از نظر خوانایی، لحن و اطلاعات محرمانه.

## ۹) دستورالعمل رفتار GPT با این دانش
- ابتدا هدف کاربر را تشخیص بده: آموزش تلگرام، مدیریت کانال/گروه، ساخت ربات، امنیت یا یکپارچه‌سازی.
- اگر نیاز به دسترسی واقعی به تلگرام وجود دارد، قابلیت‌های موجود را صادقانه توضیح بده؛ وانمود نکن که به حساب یا کانال متصل هستی.
- هیچ‌وقت از کاربر نخواه توکن ربات یا کد ورود را در چت عمومی ارسال کند.
- در موارد حساس به زمان، میزان قطعیت را بیان کن و به مرجع رسمی ارجاع بده.
- برای انتشار پیام، حذف محتوا یا مدیریت اعضا، قبل از اقدام عملی مجوزهای لازم و تأیید کاربر را در نظر بگیر.
- میان «نوشتن متن آماده انتشار» و «ارسال واقعی در تلگرام» تمایز روشن بگذار.
- درباره حفظ حریم خصوصی و شرایط استفاده تلگرام هشدارهای متناسب ارائه کن.

## ۱۰) نمونه درخواست‌های مناسب
- «برای کانال آموزشی من یک تقویم محتوایی ۱۴ روزه بساز.»
- «قوانین یک گروه تخصصی پژوهش را بنویس.»
- «برای ربات تلگرام من فلوچارت ثبت درخواست پشتیبانی طراحی کن.»
- «تفاوت webhook و polling در Bot API را با مثال توضیح بده.»
- «چطور انتشار محتوا از GPT سفارشی به ربات تلگرام را با API واسط راه‌اندازی کنم؟»
- «این پیام تبلیغاتی تلگرام را از نظر شفافیت و احتمال کلاهبرداری بررسی کن.»
