# FEZI shared prompt and skill bank

این فایل فشرده شامل محتوای بازیابی‌شده از منابع در دسترس است؛ حاوی متن کامل و کلمه‌به‌کلمه تمام چت‌های تاریخچه حساب نیست.

- `FEZI_ALL_PROMPTS_AND_SKILLS_MASTER.json.gz`: دادهٔ بانک برای پردازش سمت سرور؛ در مسیر عمومی `/public` قرار نگیرد.
- تعداد نام اسکیل‌ها: ۳٬۷۳۲؛ متن کامل در ۳٬۴۹۳ مورد در بانک تاریخی.
- بانک مرجع، مجوز اجرایی API/MCP یا نصب خودکار به پلاگین‌ها نمی‌دهد.
- اسکیل‌های ChatGPT باید از طریق ابزار رسمی Plugin Creator و دسترسی معتبر به‌روزرسانی شوند.
