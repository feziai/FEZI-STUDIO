# FEZI AGENT 0.77 — Arina interactive avatar demo

## مسیرها
- `/showcase` داشبورد اصلی برنامه‌سازی FEZI AGENT (محفوظ)
- `/arina-live` صفحه نمونه آرینا با چت متن، حرکت‌های تصویری و واکنش‌ها
- `/avatar` استودیوی قبلی ساخت آواتار (محفوظ)

## اجرا
روی Node.js 22 در محل سورس، فایل `.env` ایجاد کنید؛ `APP_PASSWORD` حداقل ۱۰ حرف و `SESSION_SECRET` مستقل حداقل ۲۴ حرف.
```bash
node --env-file=.env server.js
```

برای فعال شدن گفت‌وگوی واقعی، مدل نصب‌شده روی Ollama یا ارائه‌دهنده دیگر را در FEZI AGENT پیکربندی کنید و به محیط اضافه کنید:
`ARINA_AI_ENABLED=true`

حالت پیش‌فرض بدون مدل هوش مصنوعی **پاسخ‌های نمونه / DEMO** دارد و وانمود نمی‌کند استنتاج واقعی انجام شده است. حالت AI با درخواست‌های text-only کار می‌کند.

## تحویل داده‌ها و استوری‌بورد
- `references/arina/` عکس‌های ارسالی کاربر برای چهره و حرکت
- `public/arina-live/assets/motions/` فریم‌های کراپ‌شده برای ۱۱ حرکت
- `public/arina-live/assets/storyboard-manifest.json` منبع و فریم‌های هر حرکت
- `training/arina-chat-100.jsonl` سناریوهای ارزیابی چت (نه آموزش واقعی مدل)

## محدودیت‌های مستند
- حرکت فعلی، **تعویض فریم‌های عکس** همراه با انتقال CSS است، نه خروجی MP4 هوش مصنوعی، نه مدل ویدیوی بلادرنگ، نه lip sync.
- سرور بدون هاست دائمی، برق و شبکه پایدار نمی‌تواند ۲۴ساعته آنلاین باشد. پیام‌ها در حافظه همان پردازش نگه‌داری می‌شوند و با راه‌اندازی مجدد از بین می‌روند.
- عکس‌های چندزاویه و استوری‌بورد در پکیج حفظ شده‌اند تا بعداً توسط GPU worker یا ابزار تهیه ویدیو تبدیل به کلیپ‌های واقعی شوند.
- هیچ صدای گفتاری در نسخه جدید فعال نشده است (طبق درخواست).
- برای سایت عمومی واقعی، احراز هویت، رضایت تصویر، محدودسازی درخواست، مدیریت پیام‌های نامناسب، ذخیره‌سازی پایدار و نظارت موردنیازند.
- برچسب 'DEMO LIVE' نشان‌دهنده پیش‌نمایش تعاملی است؛ آمار بینندگان یا استریم واقعی ویدیویی جعل نشده است.

## تست‌ها
- `node --test tests/arina-live.test.js` تست ۱۵ دستور زبان طبیعی و قواعد برگرداندن state.
- `npm test` تست‌های موجود برنامه + تست‌های جدید.
- اسکرین‌شات در فایل ZIP تحویل بیرونی از رندر Chromium با همان CSS و JS گرفته شده است. اجرای مستقیم URL محلی از سوی Chromium این محیط مسدود بود؛ HTTP API جداگانه قابل آزمایش است.
