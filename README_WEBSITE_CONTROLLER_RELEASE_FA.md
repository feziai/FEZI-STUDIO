# FEZI Website Controller — ۹ نوامبر ۲۰۲۶

## وضعیت واقعی

- پلاگین شخصی FEZI Website Controller نسخه 1.0.0 در ChatGPT ثبت شد.
- سه ابزار MCP در FEZI Studio محلی فعال شدند: fezi_site_read، fezi_site_preview_replace، fezi_site_apply_replace.
- آزمون پروژه با ۵۶۵۹ تست موفق و صفر شکست گذشت.
- آزمون HTTP محلی نشان داد tools/list با احراز هویت ۲۰۰ و بدون احراز هویت ۴۰۱ می‌دهد.
- هیچ وب‌سایت آنلاین در این مرحله تغییر داده نشد.

## استفاده واقعی از ChatGPT

1. سورس سایت را روی هاست Node.js 22 و دامنه HTTPS نصب کن.
2. FEZI_AGENT_MCP_TOKEN را با رمز جدید و محرمانه در تنظیمات هاست تنظیم کن.
3. یک کانکتور یا OAuth gateway سازگار ChatGPT برای HTTPS MCP آماده کن. صرف نصب پلاگین مهارتی باعث اتصال API نمی‌شود.
4. پس از اتصال، از پلاگین بخواه پروژه را پیدا کند، فایل را بخواند، preview بدهد و فقط بعد از تأیید ذخیره کند.
5. تست‌ها و انتشار روی دامنه مرحله جداگانه است.

## سایت ساخته شده در ChatGPT Sites

لینک `sites-project://...` فقط شناسه پروژه است و مجوز ویرایش مستقیم از پلاگین ایجاد نمی‌کند. درخواست تغییر باید در همان محیط ویرایش ChatGPT Sites اعمال شود، مگر ابزار مجازِ ویرایش Sites به پلاگین متصل شده باشد. این بسته چنین ابزار داخلی ندارد.

## امنیت

- رمز یا کلید API در ZIP قرار داده نشده است.
- توکن‌های قدیمی ارسال‌شده در گفتگو باید تعویض شوند.
- قبل از اعمال تغییر، preview و SHA-256 و checkpoint الزامی است.
- این بسته امکان اجرای آزاد Shell روی سرور ایجاد نمی‌کند.
