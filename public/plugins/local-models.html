مدل‌های هوش مصنوعی سبک

این صفحه فقط وضعیت واقعی فایل‌های سرور را نشان می‌دهد. دانلود مدل با اجازه مدیر و با سقف حجم انجام می‌شود. برای اجرای مدل، کتابخانه node-llama-cpp و منابع کافی سرور لازم‌اند.

در حال بررسی...

دستور نصب سرور

npm install --no-save node-llama-cpp

npm run model:small:install

پس از نصب، متغیر LOCAL_AI_ENABLED=true را در محیط سرور فعال کن. برای مدل 135M، کیفیت فارسی محدود است؛ مدل‌های بزرگ‌تر Qwen برای فارسی مناسب‌ترند.
