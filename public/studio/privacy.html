Privacy notice — implementation status

This is a development-stage notice, not a substitute for a jurisdiction-specific final privacy policy.

Public user email, salted password verifier, profile display name, selected icon or uploaded profile photo are stored in the server's private DATA_DIR. Session cookies are signed, HttpOnly and SameSite=Lax. HTTPS and COOKIE_SECURE=true are required in production.

Community uploads remain private until explicit opt-in and owner approval. Private project data are not sent to training systems by default. Adding third-party model APIs may transmit the user's prompt and uploaded media to that provider; separate consent and notices are required before such integration.

Media storage, user deletion, backup policies, retention limits, abuse handling and data export need an operator review before a public production launch.
