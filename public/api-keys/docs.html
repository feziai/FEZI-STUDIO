مستندات API Keys

راهنمای استفاده از کاتالوگ و کلیدهای FEZI Studio در مرحله پیش‌انتشار

۱. دریافت مدل‌ها

درخواست عمومی برای دریافت مدل‌ها و قیمت‌های نمایشی با ضریب ۱٫۲۰:

GET /api/api-keys/models?q=qwen

۲. ساخت کلید خصوصی

پس از ورود به حساب FEZI، کلید را فقط یک بار مشاهده و در تنظیمات خصوصی ذخیره کن.

POST /api/api-keys/keys
Content-Type: application/json
Cookie: FEZI authenticated session
{"name":"My app"}

۳. سرویس Chat Completion

مسیر رزرو شده برای آینده:

POST /api/v1/chat/completions
Authorization: Bearer fezi_live_...
این مسیر فعلاً با 503 پاسخ می‌دهد. فروش و پردازش مصرفی تا زمان تأیید پرداخت، مجوز مدل و اتصال واقعی سرویس فعال نمی‌شود.

۴. پرداخت

کاربر یک سفارش شارژ حداقل ۱۰ دلار ثبت می‌کند. QRها، پرداخت واقعی و افزایش اعتبار فقط بعد از اتصال تأییدکننده رسمی شبکه و انتساب معتبر به فاکتور باید فعال شوند.

۵. شرایط Hugging Face

مخزن مدل یا وزن رایگان به معنی API اجرایی رایگان، اجازه فروش یا بی‌نیازی از GPU نیست. هر مدل باید مجوز و ارائه‌دهنده مجزایی داشته باشد.
