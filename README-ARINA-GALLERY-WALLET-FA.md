# FEZI Studio — Arina Gallery & Wallet (آزمایشی)

نسخه مبتنی بر FEZI AGENT v0.77. طراحی داشبورد اصلی و لایو حفظ شده و بخش‌های زیر افزوده شده‌اند:

| صفحه | مسیر |
| --- | --- |
| گالری عکس‌های تکی | `/arina-gallery` |
| کیف پول و ۲۲ گزینه ارز + QR | `/arina-wallet` |
| پیش‌نمایش اتاق خصوصی | `/arina-private` |
| استریم آرینا | `/arina-live` |
| استودیو FEZI Studio | `/showcase` |

برنامه با `Node.js >=22` و `APP_PASSWORD` (حداقل ۱۰ حرف) و `SESSION_SECRET` (حداقل ۲۴ حرف، متفاوت از رمز) اجرا می‌شود. پس از تنظیم `.env` یا متغیرهای محیطی، `npm start` را اجرا کن. راهنمای کامل: `docs/ARINA_GALLERY_WALLET_FA.md`.

**وضعیت واقعی**: گالری ۱۰ تصویر تکی، لایک/ذخیره، نمایش سه عکس و ادامه، QRها، پیش‌نمایش خصوصی و آزمون حفاظت عکس‌های ویژه آماده است. پرداخت و شارژ خودکار، تماس ویدیویی ۴۰ دقیقه‌ای و ساخت FullHD خودکار شخصیت **هنوز به سرویس‌های واقعی متصل نیستند**. هیچ مبلغی نباید قبل از تأیید اتصال دریافت شود. عکس‌های ویژه در مسیر محافظت‌شده با اعتبار واقعی باز می‌شوند. علاقه‌مندی و لایک مهمان در کوکی امضاشده باقی می‌ماند؛ برای پرداخت پول واقعی احراز هویت حساب دائمی لازم است.

آدرس‌های کیف پول *بدون تغییر حرف* در `core/arina-wallets.json` ثبت شده‌اند؛ همهٔ شبکه‌ها و مالکیت آدرس‌ها باید پیش از انتشار مالی از داخل کیف پول اصلی تأیید شوند. تصویر QR برابر متن دقیق آدرس ثبت‌شده است. اجرای رندر GPU به صورت ۱۵ کار در `render-jobs/arina-new-single-photos-15-gpu-jobs.json` برنامه‌ریزی شده، نه تولیدشده.
