# چگونه گفت‌وگوی کامل ChatGPT را ذخیره کنیم؟

این مخزن حاوی **خلاصه ساختاریافته** پروژه است، نه نسخه کلمه‌به‌کلمه تمام چت.

برای نسخه واقعی پیام‌ها:
1. در ChatGPT از قابلیت کپی یا اشتراک‌گذاری گفت‌وگو یا گزینه خروجی گرفتن از داده‌های حساب (در تنظیمات مربوطه، در صورت دسترسی) استفاده کن.
2. پیش از قرار دادن داده در GitHub، کلیدهای API، Bot Token، رمز MongoDB و اطلاعات خصوصی را حذف کن.
3. فایل خصوصی خام را در `memory/private/` نگه دار. این پوشه در Git نادیده گرفته می‌شود.
4. برای ثبت نکات قابل اشتراک، `memory/PROJECT_CONTEXT_FA.md` را به‌روز کن.

**این بسته حافظه واقعی حساب ChatGPT را تغییر نمی‌دهد و خودکار گفت‌وگو را در GitHub ذخیره نمی‌کند.**
