# حافظه ساختاریافته پروژه Fezi Studio — نسخه گردآوری‌شده

**این سند خلاصهٔ موضوعی و تصمیم‌های مهم گفت‌وگوی قابل مشاهده است، نه نسخه کلمه‌به‌کلمه تمام پیام‌ها.**
برای ذخیره نسخه کامل گفت‌وگو، باید از ابزار Export/Copy خود ChatGPT استفاده شود و قبل از هرگونه انتشار، کلیدها و اطلاعات حساس حذف شوند.

## هویت و هدف پروژه
- برند: **Fezi Studio** / فیزی استودیو.
- هماهنگ‌کننده وب‌سایت: **FEZI Agent** (نام نهایی کاربر؛ نه Free Agent).
- معماری: ChatGPT/GPT سفارشی ↔ سرور Node.js ↔ رجیستری اسکیل ↔ پایگاه دانش ↔ ربات‌های تلگرام ↔ GitHub و هاست.
- هدف رقابتی اعلام‌شده: **۶ میلیون دلار آمریکا**؛ یک هدف قابل پیگیری است نه موجودی، درآمد محقق‌شده یا تضمین‌شده.
- The Challenge: نام کانال پیشنهادی برای گزارش پیشرفت؛ تا زمان ایجاد واقعی نباید موجود اعلام شود.

## سابقه و بسته‌های مهم در گفت‌وگو
1. Project Skill Bank v1 و v2: بانک اسکیل پروژه‌ای، GPT Instructions، Knowledge و سناریوهای آزمایش.
2. AI Command Center v3/v4: مغز مرکزی، مسیریابی اسکیل‌ها، دانش تلگرام و گردش کار کنترل‌شده.
3. AI Agent Ecosystem v5/v6: اسکیل‌های GitHub، Telegram، کسب‌وکار دیجیتال، یادگیری از خطا و اتصال ابزارها.
4. Agent Fleet v8/v9: ۲۶ هویت اولیه، آواتار و سناریوهای تلگرام/GitHub؛ هزاران سناریو برابر با مهارت تضمین‌شده نیست.
5. Fezi Studio v10/v11: هفت شخصیت جدید، گالری و مینی‌اپ؛ تعداد شخصیت‌های طراحی‌شده به **۳۳** رسید.
6. v12/v13: تصاویر شخصیت‌ها، طراحی UI، سه‌بعدی، بازی و نمونه بک‌اند.
7. Fezi Deploy Bridge v1: معماری فرمان استقرار از Custom GPT با واسط GitHub و هاست (نه نصب‌شده).
8. Scholar SkillHub v1/v2 و Connect All v3: برنامه جست‌وجوی منابع بزرگ و ابزار فارسی، نه دسترسی واقعی به هر منبع.
9. لوگوی نهایی منتخب: **F بال‌دار**؛ فرم تک‌رنگ برای برند و طرح سبز فسفری/سفید برای هویت بصری وب.
10. این مخزن: پیاده‌سازی اولیه ۳۳ پروفایل در Node.js با ربات‌های Telegram و داشبورد فارسی.

## شخصیت‌ها
فهرست دقیق از `data/agents.json` بارگذاری می‌شود. شخصیت‌های شناخته‌شده شامل:
Arina، Fezi Studio، GitFez، FezPay، Super Plugin، Moderator، Bot Factory، Open Source AI،
Persian Dark Horse، FeziPay Next، Fezi Broadcast، FeziX Local AI، PDH Research، Kaizer Guard، Fezi Navigator.
تعدادی هویت/شناسه قدیمی تکراری‌اند؛ «۳۳ شخصیت» به‌معنی «۳۳ ربات ثبت‌شده واقعی تلگرام» نیست.

## قابلیت‌های موردنظر کاربر
- هر ایجنت: شخصیت و نقش مستقل، تصویر، منوی فارسی، دکمه، صفحه وب، و امکان توسعه در GitHub.
- FEZI Agent: فهم درخواست و انتخاب ابزار، پژوهش، برنامه‌نویسی، مدیریت اسکیل‌ها و دانش اشتراکی.
- آموزش: UI/UX حرفه‌ای، تایپوگرافی فارسی، تصویر و ویدیو، 3D، بازی‌سازی، Telegram Bot API، Node.js، GitHub.
- یادگیری و ارتقا: ثبت خطا، تست، مقایسه کیفیت، نسخه‌بندی و Rollback. ارتقای خودکار *تضمینی* نیست.
- منابع پژوهش: OpenAlex، Crossref، arXiv، PubMed، Semantic Scholar، GitHub، Hugging Face،
  PyPI، npm، Stack Exchange، Software Heritage، مستندات رسمی Telegram و MDN.
- اتصال‌ها: هر سرویس دارای مجوز، OAuth و/یا API Key مستقل است؛ تأیید یک‌باره عمومی برای همه سرویس‌ها وجود ندارد.
- ربات‌ها قرار است پس از اتصال و استقرار فعالیت کنند. اتصال گوشی به اینترنت نشانه اجرای سرور نیست.

## داده‌ها و محرمانگی
- در گفت‌وگو آدرس کیف پول شبکه‌های مختلف و برخی توکن‌های API مطرح شده‌اند.
- به‌دلیل امنیت و نبود تأیید صحت/مالکیت، **آدرس‌های کیف پول و هیچ توکن یا رمز واقعی داخل این مخزن عمومی قرار نگرفته**.
- داده کامل حساس را فقط در یک محل خصوصی و رمزگذاری‌شده نگهداری کن.
- فایل `memory/private/` در `.gitignore` قرار دارد. محتویات خصوصی را به مخزن عمومی Push نکن.

## واقعیت اجرایی در زمان تولید این نسخه
- کد منبع، ۳۳ پروفایل، لوگو، ۱۶ مهارت، سرویس وب و موتور ربات‌ها در بسته است.
- تا زمان وارد کردن توکن‌های جدید و استقرار واقعی، هیچ‌کدام از حساب‌های تلگرام از این مخزن فعال نیستند.
- انتشار در GitHub یا Render، ساخت حساب‌ها یا اتصال به حافظه زنده ChatGPT انجام نشده است.
- وضعیت پیاده‌سازی و منابع را با تست واقعی و لاگ‌های هاست بررسی کن.
