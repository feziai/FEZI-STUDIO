# راهنمای نگهداری ناوگان
- فقط ربات‌هایی فعال‌اند که توکن مستقل، معتبر و محیط اجرایی فعال دارند.
- برای انتشار بدون توقف نسبی از سرویس Node.js همیشه‌روشن و نظارت خطا استفاده کن.
- انتشار در کانال/گروه فقط با دسترسی ادمین و رضایت مخاطبان انجام شود.
- اجرای کار از کد بیرونی: بررسی منبع، مجوز، تست و اجرای قرنطینه‌ای قبل از تولید.
- هر تغییر خودکار کم‌خطر باید تست CI، ثبت نسخه و قابلیت بازگشت داشته باشد.
- انتشار کلیدها، برداشت دارایی، ساخت حساب جعلی و ارسال پیام ناخواسته جزو وظایف مجاز این نسخه نیست.
- UI فارسی: جهت RTL؛ رندر متن روی تصویر پس از تولید، با فونت مناسب و دارای مجوز.
- ربات‌های تلگرام حساب انسانی یا گروه جدید را مستقلاً از طریق Bot API ایجاد نمی‌کنند.
