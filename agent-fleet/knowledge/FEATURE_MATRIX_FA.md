# ماتریس وضعیت واقعی قابلیت‌ها

| قابلیت | در این بسته | شرایط عملیاتی |
|---|---|---|
| ۳۳ پروفایل و آواتار | پیاده‌سازی‌شده | قابل نمایش فوری |
| داشبورد فارسی | پیاده‌سازی‌شده | سرور Node.js باید اجرا شود |
| Telegram getUpdates و دکمه‌ها | پیاده‌سازی‌شده | به ازای هر حساب BotFather، توکن معتبر و مجزا |
| پاسخ‌گویی AI متنی | پیاده‌سازی‌شده با API اختیاری | OPENAI_API_KEY، اتصال شبکه، هزینه |
| ChatGPT GPT Actions | Schema آماده | دامنه HTTPS + تنظیم در GPT Builder |
| جست‌وجوی OpenAlex و Crossref | در فهرست منابع | اتصال واقعی در نسخه دیگر، اینجا اجرا نشده |
| GitHub تغییر فایل و ایجاد PR | در طرح | OAuth/GitHub App و اجرای جداگانه |
| ساخت سایت/گروه/حساب خودکار | پیاده‌سازی نشده | هر پلتفرم محدودیت و دسترسی مستقل دارد |
| دریافت خودکار وجه | پیاده‌سازی نشده | ارائه‌دهنده پرداخت و تأیید تراکنش واقعی |
| تولید عکس/ویدیو | فقط تخصص شخصیتی | نیازمند مدل و API یا ابزار اجرایی مجزا |
| استریم ۲۴ ساعته | پیاده‌سازی نشده | زیرساخت پخش و سرور بدون توقف |
| بهبود خودکار کد | CI هفتگی فقط تست | نیازمند عامل کدنویس، ارزیابی و محیط تست |
| میزبانی مستقیم در GitHub | نه | GitHub محل کد و Actions CI است؛ اجرای ربات در هاست |
| ذخیره گفت‌وگوی کامل ChatGPT | نه | خلاصه در memory/ و خروجی گرفتن دستی از چت |

این فهرست برای جلوگیری از ادعای عملکردی نوشته شده که هنوز ساخته یا نصب نشده است.
