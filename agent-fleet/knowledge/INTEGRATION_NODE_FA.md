# اتصال به سایت Node.js فعلی فیزی استودیو

این مخزن یک سرویس مستقل است. اگر سایت قبلی در Replit/GitHub یا سرور دیگر وجود دارد،
آن را **جایگزین نکن**؛ می‌توانی FEZI Agent Fleet را به‌صورت سرویس جداگانه مستقر کنی.

- پیشنهاد: `agents.your-domain.example` ← Render این مخزن
- سایت اصلی `www.your-domain.example` می‌تواند از سرور خودش
  با `GET /api/agents` و `GET /api/status` وضعیت را بخواند.
- درخواست Chat خصوصی را **فقط از سمت سرور** با `Authorization: Bearer $DASHBOARD_TOKEN` به
  `POST /api/chat` ارسال کن. هرگز `DASHBOARD_TOKEN` را در JavaScript عمومی سایت اصلی قرار نده.
- داده مشترک و اسکیل‌های بیشتر باید از پایگاه داده یا API اختصاصی طراحی شوند؛
  این نسخه فایل‌محور است و اطلاعات زنده سایت قبلی را نمی‌خواند.
- برای استقرار با مقیاس بیشتر، هر Telegram Bot باید فقط یک Poller/Webhook فعال داشته باشد.

این نمونه برای ادغام اولیه است نه اتصال خودکار به کد اختصاصی سایت قبلی.
