# چک‌لیست مرحله‌ای انتشار

- [ ] ZIP را استخراج و تمام محتوای پوشه را در GitHub (ترجیحاً خصوصی) Commit کرده‌ام.
- [ ] GitHub Actions → CI اجرا شده و همه تست‌ها سبز هستند.
- [ ] هاست Node.js (مثل Render) با مخزن GitHub متصل است.
- [ ] `DASHBOARD_TOKEN` به صورت Secret حداقل ۳۲ کاراکتری تنظیم شده.
- [ ] برای هر رباتی که می‌خواهم آنلاین شود، BotFather توکن جدید صادر کرده.
- [ ] `BOT_TOKEN_*` مربوط به هر شخصیت را فقط در Environment هاست گذاشته‌ام.
- [ ] هیچ فایل `.env` یا کلید محرمانه‌ای در GitHub قرار نداده‌ام.
- [ ] در صورت لزوم Webhook قبلی تلگرام را پاک کرده‌ام.
- [ ] هاست همیشه‌روشن است و تنها یک Poller برای هر توکن فعال است.
- [ ] پاسخ `GET /health` را دیده‌ام و وضعیت ربات‌ها را در داشبورد بررسی کرده‌ام.
- [ ] از تلگرام پیام `/start` را به هر ربات واقعی فرستاده و پاسخ دریافت کرده‌ام.
- [ ] برای پاسخ هوشمند، کلید مدل AI تنظیم و هزینه و حد مصرف بررسی شده.
- [ ] برای GPT سفارشی، آدرس HTTPS در `gpt/openapi.yaml` جایگزین و Action نصب شده.
- [ ] در صورت وجود داده حساس در خروجی واقعی چت، آن را به GitHub عمومی منتقل نکرده‌ام.

**GitHub محل ذخیره کد و اجرای تست است، نه هاست همیشگی ربات‌های تلگرام.**
