# FEZI Studio — GitHub Agent Fleet v1.0

**این یک مخزن اجرایی آمادهٔ انتشار است، نه وعدهٔ اجرای خودکار با آپلود در GitHub.**

## چه چیزی داخل بسته هست؟
- ۳۳ پروفایل ایجنت از بسته Fezi Studio v13، هرکدام با نقش، تصویر SVG و نام متغیر توکن اختصاصی
- بک‌اند Node.js بدون وابستگی خارجی؛ وب‌سایت فارسی، API وضعیت، و موتور چندرباتی Telegram
- منوی `/start`، `/help`، `/skills`، `/agents`، `/status`، `/challenge` و دکمه‌های درون پیام
- پاسخ مدل AI **فقط در صورت تنظیم** `OPENAI_API_KEY`؛ در غیر این صورت پیام راهنمای شفاف
- تست‌های CI برای GitHub Actions، `Dockerfile`، `docker-compose.yml` و `render.yaml`
- خلاصه قابل استفاده‌مجدد از تصمیم‌های گفت‌وگو در `memory/PROJECT_CONTEXT_FA.md`

## راه‌اندازی در کامپیوتر
1. Node.js نسخه ۲۰ یا جدیدتر نصب کن.
2. پوشه مخزن را استخراج کن و در ترمینال وارد آن شو.
3. دستور `cp .env.example .env` را اجرا کن (در ویندوز فایل را دستی کپی کن).
4. متغیر `DASHBOARD_TOKEN` را با یک رمز طولانی تصادفی پر کن.
5. برای هر ربات واقعی، توکن **جدید** BotFather را در `BOT_TOKEN_<ID>` مربوطه تنظیم کن.
6. در صورت نیاز پاسخ‌گویی AI، کلید معتبر مدل را در `OPENAI_API_KEY` بگذار.
7. `npm test` و سپس `npm start` را اجرا کن.
8. در مرورگر `http://localhost:10000` را باز کن.

## GitHub + Render
1. یک مخزن **خصوصی** بساز و **فقط فایل‌های داخل این پوشه** را Push کن.
2. اصلاً فایل `.env`، توکن‌ها، رمزها، پشتیبان خام مکالمه و کلیدهای قبلی را Commit نکن.
3. از داشبورد Render یک Web Service با اتصال GitHub یا Blueprint با `render.yaml` بساز.
4. در بخش Environment متغیرهای واقعی `DASHBOARD_TOKEN`، `BOT_TOKEN_ARINA` و بقیه را قرار بده.
5. برای پاسخ مدل، `OPENAI_API_KEY` را (اختیاری) وارد کن.
6. پس از Deploy، `/health` باید `ok:true` بازگرداند و کارت ربات با توکن صحیح به حالت «متصل» درآید.
7. در تلگرام به **نام کاربری واقعی همان ربات** پیام `/start` بده.

> GitHub Actions فقط تست می‌کند و نمی‌تواند ۳۳ ربات را با آپلود فایل ۲۴ساعته روشن نگه دارد.
> برای اجرای همیشگی، سرویس Node.js باید پایدار و بدون Sleep باشد؛ یک Instance برای هر توکن
> از تداخل `getUpdates` جلوگیری می‌کند. سرویس رایگان ممکن است متوقف/خوابانده شود.

## نکات اتصال و دسترسی
- این نسخه اتصال خودکار به حساب GitHub/Replit، ساخت حساب Telegram، ساخت ۳۳ ربات یا انتشار بدون مجوز ندارد.
- هر شخصیت فقط با **توکن واقعی و مجزا** فعال می‌شود. حساب یا توکن تکراری دو ربات مستقل نیست.
- اگر برای ربات‌ها قبلاً Webhook تنظیم شده، اول آن را در سرویس قبلی قطع کن؛ سپس
  `TELEGRAM_CLEAR_WEBHOOKS=true` را برای **اولین اجرا** موقتاً تنظیم کن و دوباره false کن.
- یک رمز مشترک نمی‌تواند جایگزین مجوزهای سرویس‌های دیگر شود.
- برای اتصال GPT Builder، فایل `gpt/openapi.yaml` پس از استقرار HTTPS قابل استفاده است.
- عملیات پرخطر مانند انتقال دارایی، انتشار پیام عمومی یا تغییر مجوزها در این نسخه خودکار نیستند.

## مسائل امنیتی
- به توکن‌هایی که در گفت‌وگو یا فایل‌های قبلی قرار داده شده‌اند اعتماد نکن؛ توکن جدید صادر کن.
- `DASHBOARD_TOKEN` باید قوی و محرمانه بماند. چت وب‌سایت بدون این توکن غیرفعال است.
- هیچ کلید محرمانه یا آدرس کیف پول از مکالمات گذشته در مخزن کپی نشده است.
- این سامانه وضعیت **واقعی تنظیم‌شده** را نشان می‌دهد، نه «درآمد فعلی»، «ارتقای تضمینی» یا «ربات‌های آنلاین» ساختگی.

## شروع سریع برای یک ربات
- از BotFather ربات Arina را بساز/توکنش را تعویض کن.
- در هاست `BOT_TOKEN_ARINA=...` را فقط در Secrets تنظیم کن.
- پس از راه‌اندازی `/health` را چک کن، سپس `/start` را به خود ربات بفرست.
- برای سایر ربات‌ها هم نام متغیر دقیق در `.env.example` و `data/agents.json` وجود دارد.

## نقش FEZI Agent
FEZI Agent نام صحیح مغز مرکزی وب‌سایت است. «Free Agent» نام قبلی بود و نباید به‌جای آن استفاده شود.

**نکته آپلود:** ZIP را اول استخراج کن؛ در GitHub گزینه Add file → Upload files را بزن و محتوای پوشه را بارگذاری کن، نه خود فایل ZIP را. سپس Render را متصل کن.
