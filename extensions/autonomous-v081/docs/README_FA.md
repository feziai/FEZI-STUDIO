# FEZI Studio integration kit 0.80

این بسته **افزونه** است و نسخه کامل FEZI Studio نیست. ۳۵ مخزن در کاتالوگ قرار گرفته‌اند اما هیچ‌کدام به‌صرف حضور در کاتالوگ نصب یا تست‌شده محسوب نمی‌شوند. همه به‌طور پیش‌فرض غیرفعال هستند.

## آماده‌سازی

```bash
node --version  # >= 22
npm test
npm run demo
```

## روش اتصال

- Ollama: ابتدا Ollama و مدل را روی رایانه یا سرور خود نصب کنید؛ آدرس localhost فقط زمانی صحیح است که FEZI و Ollama روی یک ماشین باشند.
- llama.cpp / vLLM / LiteLLM: سرویس OpenAI-compatible را راه بیندازید و از `openaiCompatible` استفاده کنید؛ کلید API فقط در متغیر محیطی سرور.
- ComfyUI: ابتدا GPU، checkpoint دارای مجوز و workflow API-format معتبر تهیه کنید. `enqueue()` فقط شناسه صف می‌گیرد و خودش ویدیو تولید نمی‌کند.
- سایر ۳۱ مورد: مستقل ثبت شده‌اند، **adapter اجرایی ادغام‌شده ندارند**. اتصال CLI و سرویس‌های مدیریت‌شده باید بعد از بررسی فرمان‌ها، نسخه، مجوز و sandbox به‌طور جداگانه افزوده شود. هرگز اجرای دلخواه shell از درخواست کاربر عمومی انجام ندهید.

## وارد کردن پروژه

`safe-import.mjs`: از GitHub با git clone، از ZIP با اعتبارسنجی مسیر و اندازه، و از پوشه محلی با حذف .env و .git پشتیبانی می‌کند. برای استفاده عمومی باید احراز هویت، quota، sandbox، اسکن فایل، کنترل DNS و network egress و محدودیت‌های OS نیز فعال شود؛ واردکردن کد **به معنای اجرای امن کد آن نیست**.

## سیاست مدل و مجوز

از Router v0.79 برای رتبه‌بندی مدل‌های واقعاً ready استفاده کنید. در Image/Video فقط مدل انتخابی کاربر. برای فعالیت تجاری قوانین WebContainers، n8n و Open WebUI باید جداگانه بررسی شود. هیچ مدل، وزن یا افزونه‌ای همراه این بسته دانلود نشده است.

## گزارش آزمون

تست HTTP واقعی روی mock local endpoint اجرا می‌شود تا ساخت درخواست/خواندن جواب/خطا ارزیابی شود، نه اینکه ادعای نصب یا تولید واقعی AI شود. تست GPU/CLI/OAuth/بسته Android/لایو هنوز نیازمند زیرساخت است.
