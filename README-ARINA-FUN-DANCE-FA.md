# FEZI AGENT 0.77 · Arina Live — Fun Dance Upgrade

نسخه جدید همان UI قبلی FEZI Studio را نگه می‌دارد. `Arina Live` فقط یک نمونه از برنامه‌ساز اصلی است؛ سه چهره دیگر در کارت‌های گالری باقی مانده‌اند اما پخش زنده مستقل ندارند. صدا/صحبت آرینا غیرفعال است و پاسخ‌ها متنی هستند.

## اجرای Node.js 22

```bash
APP_PASSWORD='change-me-very-long-password' SESSION_SECRET='replace-with-different-long-random-secret' PORT=3000 node server.js
```

بازکردن `/showcase` و `/arina-live`.

## تغییرات

- ۵۲ تعریف حرکت در ۵ سبک موسیقی و رقص؛ طرح ۶۰ و ۱۲۰ ثانیه‌ای در `render-jobs/`.
- مدیا به‌صورت قطعه ویدیویی واقعی MP4 مورد انتظار است؛ اسلایدشوی بریده‌شده دیگر در اجرا استفاده نمی‌شود.
- پلیر ویدیو برای همه افراد یک صحنه مشترک با تایم‌کد سرور دارد. هنگام نبود MP4، آواتار به‌صورت تصویر مرجع مشخصاً در حالت دمو است و رقص اجراشده ادعا نمی‌شود.
- موسیقی بی‌کلام آزمایشی اورجینال با ریتم‌های مختلف و ولوم تطبیقی.
- ابزار ارزیابی و مونتاژ کلیپ‌های هم‌ژست در `scripts/arina-video-pipeline.mjs`؛ محافظ کیفیت 1080p.
- همه تصاویر رفرنس قدیمی و استوری‌بوردهای جدید در `references/arina/` و استفاده نکردن از آن‌ها به‌عنوان «فیلم».
- تنها آرینا در وضعیت Live است. دیگر مدل‌ها در گالری قابل انتخاب و شخصی‌سازی‌اند ولی Live نیستند.

## تست و محدودیت

`npm test` ← ۵٬۴۱۶ تست موفق، صفر شکست در ۲۰۲۶-۱۱-۰۱. فایل‌های `.tap` گزارش آزمون هستند.

**توجه:** هیچ MP4 جدیدی توسط GPU تولید نشده و خروجی ۱ تا ۲ دقیقه‌ای با چهره واقعی هنوز موجود نیست. برای رسیدن به آن باید ویدیوهای راهنمای حرکت با حق استفاده، ComfyUI/Wan2.2 Animate و GPU مناسب را اجرا کرد، بعد کلیپ‌ها را بازبینی و از ابزار انتشار استفاده کرد. تفصیل در `docs/ARINA_FULLHD_DANCE_FA.md`.
