راه‌اندازی و اتصال

  1. Deploy the FEZI Studio Node.js backend to an authorized always-on server with HTTPS.
  2. بک‌اند Node.js فضی استودیو را روی هاست دائمی و HTTPS نصب کن.
  3. Configure approved per-plugin API credentials / MCP / BotFather settings on the server — not in GitHub.
  4. کلیدهای API، تنظیمات MCP یا BotFather را فقط در محیط امن سرور تنظیم کن، نه GitHub.
  5. Verify operations and permissions with a real authorized test.
  6. فعال‌شدن واقعی را با تست عملی و مجوز معتبر تأیید کن.
