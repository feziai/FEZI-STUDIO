  2. بک‌اند Node.js فضی استودیو را روی هاست دائمی و HTTPS نصب کن.

  5. Verify operations and permissions with a real authorized test.
  6. فعال‌شدن واقعی را با تست عملی و مجوز معتبر تأیید کن.
