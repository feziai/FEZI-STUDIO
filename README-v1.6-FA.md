# FEZI Studio v1.6 — نسخه کامل با Prompt Library

این بسته یک نسخه ادغام‌شده از v1.5 است؛ تمام فایل‌های قبلی، موتور اصلی FEZI AGENT، Studio، Arina، آموزش‌ها، تسک‌ها، FAQ، APIها و ابزارها نگهداری شده‌اند. بخش Prompt Library روی همان `server.js` اجرا می‌شود و به سرور دوم نیاز ندارد.

## مسیرها

- `/prompts` — کتابخانه پرامپت‌ها با جستجو، دسته‌بندی، کارت‌ها، تصاویر مرجع و منابع بیرونی.
- `/prompts/<slug>` — صفحه مستقل هر پرامپت؛ برای متن‌های دارای مجوز دکمه Copy و Use in AI Studio دارد.
- `/api/prompts?q=...&category=...&kind=...&page=1&limit=36` — API عمومی رکوردهای منتشرشده.
- `/api/prompts/sources` — فهرست منابع خارجی همراه با وضعیت حقوق انتقال.
- `/sitemap-prompts.xml` — سایت‌مپ اختصاصی؛ `/sitemap.xml` اصلی نیز صفحات قابل‌کپی را شامل می‌شود.
- `/admin/prompts` — واردسازی پرامپت با مجوز ثبت‌شده؛ ورود مالک الزامی است.
- `/api/admin/prompts/import` — API واردسازی دسته‌ای ۱ تا ۲۵ رکورد در هر درخواست؛ ورود مالک الزامی است.
- `/admin/assistant` — گفت‌وگوی مدیر با مدل تنظیم‌شده برای پیشنهاد و بررسی تغییرات؛ **فقط حالت پیشنهاد و بررسی**، بدون اعمال خودکار کد.
- `/contact` — راه ارتباطی پشتیبانی.
- `/cookie-consent.js` — پیام رضایت کوکی با دو انتخاب واقعی.

## موجودی آغازین و منابع

۲۷ کارت: ۲۳ پرامپت قابل‌کپی و اصیل FEZI؛ ۴ ارجاع صرفاً پیوندی (متن پرامپت قابل کپی نیست). ۶ منبع بررسی‌شده: `generateprompt.net`، `media.io/ai/explore`، `fashiondiffusion.ai/ai-prompts/ai-hot-prompts`، `aixplore.in/prompts`، `promptbase.com`، `postcrest.com/ai-image-prompts/best-ai-prompts-for-beautiful-girls`.

**هیچ انتقال حجمیِ تأییدنشده‌ای از منابع انجام نشده است.** عنوان/آدرس منبع با متن و تصویر دارای حق بازنشر فرق دارد. مخصوصاً فروشندگان PromptBase عموماً مجوز توزیع مجدد متن فروخته‌شده را نمی‌دهند. ادعای مالکیت عمومی نسبت به همه رکوردهای بازارها به معنی مالکیت محتوای سایر فروشندگان نیست.

## افزودن آرشیوهای متعلق به مالک

۱. از مرورگر وارد `/builder` شو، با رمز مالک وارد شو.
۲. به `/admin/prompts` برو.
۳. نمونه `config/prompt-transfer-template-v16.json` را باز و رکوردهای واقعی خودت را در آن جایگزین کن.
۴. فقط رکوردهایی را وارد کن که متن آنها **واقعاً حق بازنشر** دارد و برای **هر تصویر/ویدیو** مجوز نمایش مستقیم یا hotlink وجود دارد. در صورت `rights` غیر از `original`، باید `rightsEvidence` آدرس HTTPS سند مجوز یا رضایت صاحب اثر باشد.
۵. تیک تأیید حق انتقال را بزن و دکمه Import را انتخاب کن؛ رکوردها در مسیر خصوصی `DATA_DIR/prompts-v16/imported.json` ذخیره می‌شوند. برای جلوگیری از گم شدن داده، `DATA_DIR` را به پوشه‌ای پایدار روی هاست متصل کن.
۶. وارد `/prompts` شو؛ هر صفحه مستقل پس از واردسازی در سایت‌مپ قرار می‌گیرد. ایندکس شدن در Google تضمین‌شده نیست و به قوانین موتور جستجو بستگی دارد.

قالب رکورد:

```json
{
  "slug": "my-original-prompt-2026",
  "title": "My Original Prompt",
  "titleFa": "پرامپت اختصاصی",
  "description": "Original FEZI Studio content",
  "category": "Fashion",
  "kind": "image",
  "prompt": "A full original creative prompt…",
  "rights": "original",
  "transferAllowed": true,
  "sourceId": "owner-import",
  "sourceUrl": "",
  "media": [
    {"type":"image","url":"https://your-domain.example/image.jpg","transferAllowed":true},
    {"type":"video","url":"https://your-domain.example/video.mp4","transferAllowed":true}
  ]
}
```

برای مجوز CC BY / اجازه صریح، مقدار `rights` را `cc-by-4.0` یا `explicit-permission` و `rightsEvidence` را نشانی مدرک قرار بده. تایید مالکیت شرط لازم است، نه جایگزین بررسی مجوز هر منبع.

## اجرای پروژه

Node.js **22 یا بالاتر**، `APP_PASSWORD` حداقل ۱۰ کاراکتر، `SESSION_SECRET` حداقل ۲۴ کاراکتر، `DATA_DIR` پایدار و `PUBLIC_BASE_URL=https://YOUR-DOMAIN` را در متغیرهای محیطی قرار بده.

```bash
npm test
npm start
```

اجرای وب‌سایت مستقیماً از **GitHub Pages** برای این پروژه ممکن نیست؛ چون بک‌اند Node.js دارد. مخزن GitHub کد را نگه می‌دارد و انتشار از طریق GitHub Actions به هاست Node.js/cPanel نیاز دارد.

### پشتیبانی و ایمیل

آیدی تلگرام `@PDH_sup` در صفحه `/contact` قرار دارد. رشتهٔ ارسالی `Persiandarkhorsesup.gmail.com` آدرس ایمیل معتبر نیست؛ آن را به آدرس حدسی تبدیل نکردیم. بعد از ارائه آدرس درست، `SUPPORT_EMAIL` را روی هاست تنظیم کن. اعلان ایمیلی خودکار نیز تا اتصال سرویس ارسال ایمیل **فعال نیست**.

### ورود، کوکی و امنیت

ورود ایمیلی در نسخه ۱.۵ حفظ شده است. ورود مستقیم Google/Apple تا راه‌اندازی OAuth و اعتبارسنجی سرور **فعال نیست**. کوکی‌های ضروری و اختیاری دو انتخاب واقعی دارند؛ گزینه Essential به معنی Accept All نیست. این بسته اسکریپت آنالیتیکس اختیاری فعال ندارد.

سیستم لایو آرینا بیننده ساختگی ثبت نمی‌کند؛ تعداد واقعی کاربر و رأی‌گیری حرکت‌ها در هسته قبلی حفظ شده‌اند. محتوا و عکس کاربران به‌صورت خصوصی نگهداری می‌شود و برای انتشار به رضایت کاربر و تأیید مدیر نیاز است.

### AI دستیار مدیر

صفحه `/admin/assistant` در صورت اتصال یک مدل مناسب پاسخ واقعی می‌دهد اما فقط طرح/پیشنهاد می‌دهد. این نسخه نه اتصال مستقیم به اشتراک ChatGPT همین حساب دارد و نه مجاز است بدون تأیید صاحب سایت کد در محیط production را تغییر دهد. اتصال OAuth، MCP یا افزونه ChatGPT به تنظیمات جداگانه نیاز دارد.
