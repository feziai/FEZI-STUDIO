# FEZI AGENT — نسخه 0.77

## خلاصه دقیق

این بسته ادامه سورس نسخه 1.0 قبلی با **شماره انتشار درخواستی 0.77.0** است. نام نمایشی همواره **FEZI AGENT** است. ۱۵ تعریف مدل هوش مصنوعی جدید (به‌جز سه مدل موجود قبلی) با نقش تخصصی ثبت شده‌اند: درمجموع ۱۸ انتخاب مدل.

**کد و کاتالوگ مدل، وزن مدل نیستند.** نصب وزن‌ها، Ollama یا Workerهای صوت/تصویر/ویدیو و GPU نیازمند آماده‌سازی مستقل است. سرور cPanel اشتراکی معمولاً ظرفیت اجرای همه مدل‌ها را ندارد.

## امکانات نسخه جدید

- نام FEZI AGENT و نسخه 0.77 در health، بسته Node.js و صفحه ورود.
- مسیریاب توانمندی‌محور جدید: کدنویسی سبک/پیشرفته، بازبینی، ترجمه، برنامه‌ریزی، استدلال، خلاصه‌سازی، جست‌وجو، تشخیص متن در تصویر، گفتار، تصویر و ویدیو.
- انتخاب مدل فقط از موجودی نصب‌شده و قابل‌تشخیص Ollama. فهرست مدل‌های صرفاً ثبت‌شده، «آماده اجرا» تلقی نمی‌شوند.
- یک رابط اختصاصی برای تصویر، ویدیو، صوت و OCR که در صورت عدم اتصال Worker به‌جای خروجی جعلی، خطای روشن بازمی‌گرداند.
- API عمومی خلاصه قابلیت‌ها بدون نمایش نام مدل‌ها: `GET /api/fezi/capabilities`.
- جزئیات فنی مدل‌ها **فقط برای مدیر لاگین‌شده**: `GET /api/fezi/admin/models`.
- اجرای Worker امن و اختیاری از مسیر `POST /api/fezi/specialist` با توکن سروری، HTTPS و جلوگیری از redirect.
- تست‌های جدید برای انتخاب واقعی مدل نصب‌شده، احراز هویت، وضعیت Worker و تشخیص درخواست‌های فارسی.

## نصب

```bash
cp .env.example .env
# تنظیم APP_PASSWORD و SESSION_SECRET قوی و مستقل در .env
node --env-file=.env server.js
```

برای مشاهده ۱۵ مدل جدید، نقش‌ها و دستورهای نصب:

```bash
npm run models:catalog
```

نمونه برای نصب مدل کدنویسی جدید روی **ماشین جداگانه‌ای که Ollama دارد**:

```bash
ollama pull qwen2.5-coder:7b
ollama pull qwen3:1.7b
```

اگر Ollama روی ماشین دیگری است، آدرس سرویس را در `OLLAMA_BASE_URL` با شبکه خصوصی امن تنظیم کنید. سرویس Ollama خام را در اینترنت عمومی قرار ندهید.

## اجرای ابزار تصویر / ویدیو / صوت

از `FEZI_WORKER_URL` به یک سرویس اجرای واقعی با پروتکل زیر استفاده کنید. برای آدرس بیرونی HTTPS و `FEZI_WORKER_TOKEN` الزامی است. **نسخه 0.77 تنها کلاینت Worker را می‌آورد؛ خود مدل و runtime در cPanel به‌صورت خودکار نصب نمی‌شود.**

درخواست داخلی از FEZI AGENT به Worker:

```json
{"role":"image","model":"black-forest-labs/FLUX.1-schnell","prompt":"forest in fog","inputs":{}}
```

پاسخ معتبر تنها پس از تولید خروجی واقعی:

```json
{"ok":true,"summary":"Generated one image","artifact":"https://your-worker-host/path/to/generated-file.png"}
```

اگر کار در صف است، Worker باید آن را با وضعیت مناسب گزارش کند؛ `ok:true` نباید قبل از تولید خروجی واقعی فرستاده شود. اطلاعات مجوزها و مدل‌ها فقط در بخش مدیر نگه داشته می‌شوند؛ با پرسش مستقیم درباره سازوکار، سیستم باید صادق باشد.

## اجرای آزمون‌ها

```bash
npm test
npm run qa:55m
```

`qa:55m`، ۱۱ دسته و در هر دسته ۵ میلیون ورودی قطعی را بررسی می‌کند (مجموع **۵۵ میلیون بررسی invariant**). نتیجه قابل تکرار در `QA/qa-55m-results.json` و لاگ `QA/qa-55m-console.log` نوشته می‌شود. برای اجرای سریع:

```bash
FEZI_QA_CASES_PER_SUITE=1000 npm run qa:55m
```

این **معادل ۵۵ میلیون اجرای مدل، درخواست اینترنتی، تست بار، تست GPU یا مقایسه با Replit نیست**. برای مقایسه واقعی با Replit، معیارهایی مانند موفقیت ساخت پروژه، زمان، کیفیت کد، موفقیت استقرار و میزان خطا باید به‌طور مستقل اندازه‌گیری شوند.

## فهرست مدل‌ها و مجوز

فایل `docs/MODELS_15_NEW_FA.md` حاوی مشخصات فنی کامل ۱۵ مدل اضافه و سه مدل سابق است. قبل از توزیع وزن هر مدل، اطلاعیه‌های upstream و شرایط وابستگی‌ها را کنترل و حفظ کنید.

## محدودیت‌های باقی‌مانده

- مدل‌های جدید فقط به‌صورت نقش و adapter ثبت شده‌اند؛ فایل وزن در ZIP نیست.
- رندر تصویر/ویدیو و ساخت APK/IPA به Workerهای عملیاتی و زیرساخت نیاز دارند.
- هیچ بنچمارک مستقیمی مقابل Replit اجرا نشده؛ ادعای «بهتر از Replit» تأیید نمی‌شود.
- پلاگین ChatGPT MCP همچنان نیازمند استقرار HTTPS و احراز هویت تولیدی است.
