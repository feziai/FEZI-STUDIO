# FEZI Studio — GitHub Pages و ۲۶ پلاگین

✅ **یک بسته GitHub-ready** برای وب‌سایت Node.js 22 و ساخت ۲۶ صفحه اختصاصی GitHub Pages، براساس نسخه‌های خصوصی ثبت‌شدهٔ Plugin Creator در ۱۱ نوامبر ۲۰۲۶.

- برای شروع: [GITHUB_INSTALL_FA.md](./GITHUB_INSTALL_FA.md)
- فهرست نسخه‌ها: [catalog/current-plugin-versions.json](./catalog/current-plugin-versions.json)
- صفحات ایستا: [`_github_pages/`](./_github_pages/)
- Github Actions: [deploy-fezi-plugin-pages.yml](./.github/workflows/deploy-fezi-plugin-pages.yml)
- تولید مجدد: `npm run pages:build`
- کنترل امنیت: `npm run github:preflight`
- آزمون‌ها: `npm test`

GitHub Pages یک **فهرست عمومی** است؛ سرویس‌های ChatGPT Plugin, Telegram, MCP, AI model, FeziPay با هاست اجرایی و مجوز خود کار می‌کنند. ساخت هر صفحه GitHub به معنی آنلاین‌شدن هر پلاگین نیست.

آدرس احتمالی بعد از انتشار موفق: `https://feziai.github.io/FEZI-STUDIO/`.
