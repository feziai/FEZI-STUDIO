# FEZI Studio v1.4 — FULL MERGED (پکیج کامل)

این نسخه **بر پایه فایل کامل نسخه ۱.۳** است؛ لندینگ جدید جایگزین هسته برنامه نشده است.

## اجرا

**پیش‌نیاز:** Node.js نسخه ۲۲ یا بالاتر، ترمینال یا هاست Node.js واقعی. روی اندروید فقط با باز کردن HTML داخل ZIP سرور و دیتابیس اجرا نمی‌شوند.

```bash
cd FEZI_STUDIO_v1.4_MERGED_FULL
cp .env.example .env
# مقادیر APP_PASSWORD و SESSION_SECRET را با مقادیر قوی و اختصاصی در محیط هاست تنظیم کنید.
# در محیط تولید از APP_PASSWORD طولانی و SESSION_SECRET متفاوت و تصادفی استفاده کنید.
npm start
```

در محیط محلی آدرس `http://127.0.0.1:3000` را در مرورگر باز کنید. در هاست Node.js آدرس دامنه میزبان را باز کنید.

## نقشه صفحات

- `/` لندینگ جدید سفید/آبی/صورتی با عکس جدید آرینا و لوگوی اصلی F بدون تغییر، لینک‌های قابل‌کلیک و چهار چهره نمایشی
- `/builder` برنامه‌ساز **اصلی v1.3** با ورود مدیر، مدیریت فایل، پیش‌نمایش، خروجی، AI، مدیریت آکادمی و غیره؛ همه حفظ شده‌اند
- `/showcase` داشبورد Showcase قبلی، برای حفظ سازگاری
- `/arina-live` اتاق چت آرینا با واکنش متنی/صحنه و پخش کلیپ در صورت وجود فایل تأییدشده
- `/arina-gallery` آلبوم قبلی، `/arina-wallet` پرداخت تأییدشده (اگر تنظیم باشد)، `/arina-private` اتاق خصوصی
- `/avatar` استودیوی ساخت آواتار، `/free-ai` مدل‌های متن‌باز، `/toolbox` فهرست ۸۱ ابزار
- `/faq` چهل سؤال رسمی و انجمن ثبت سؤال با تأیید مدیر؛ `/admin/faq` بررسی پرسش‌های در انتظار (ورود مدیر لازم است)
- `/health` گزارش سلامت سرور

## تغییرات جدید

- تم سفید ۷۵٪، آبی، صورتی، واکنش‌گرا
- استفاده از فایل اصلی لوگوی خرگوشی F، برابر بیت‌به‌بیت با فایل ارسال‌شده
- عکس آرینا با کلاه صورتی و کارت‌های Saba، Arwin، Carmella و Manika (نمایشی، بدون کلیک)
- مسیر واقعی سرویس‌ها: تصویر/ویدیو → `/free-ai`، تلگرام/واتساپ/هاست → ارسال ایده به `/builder`، FAQ → `/faq`، لایو → `/arina-live`، گالری → `/arina-gallery`
- ۴۰ FAQ رسمی + ثبت سؤال با اعتبارسنجی، محدودسازی ارسال و تأیید مدیر در سرور؛ امتیاز ۱ تا ۵
- پوشه `extensions/autonomous-v081`: افزونه‌ها و قالب‌های ۷۰ MCP جدید به‌صورت **اختیاری و غیرفعال**، بدون دستکاری خودکار مدل‌ها یا عملکرد قبلی
- اسناد نسخه 0.82 در `docs/master-v082` برای مراجعه؛ نه جایگزین کد اصلی.

## چه چیزهایی واقعاً متصل نیستند؟

- تولید ویدیو و حرکت پیوسته آرینا فقط پس از ساخت و تأیید MP4 واقعی؛ بدون GPU سرور امکان پخش است اما ویدیو ساخته نشده.
- ربات واتساپ، مدیریت سرور cPanel از راه دور و استقرار GitHub فقط با اتصال سرویس و مجوزهای واقعی قابل اجرا هستند. دکمه لندینگ آنها **درخواست ساخت پروژه** را در سازنده باز می‌کند، نه اینکه سرور را بی‌اجازه تغییر دهد.
- API مدل‌های تصویر/ویدیو و مدل چت آرینا ممکن است روی هاست نصب نشده باشند.
- پرداخت هدیه و قفل عکس فقط پس از تأیید وبهوک معتبر سرویس پرداخت قابل استفاده است.
- ورود عمومی چندکاربره و اتصال OAuth هنوز در هسته v1.3 نیست؛ محیط مدیریت با APP_PASSWORD محافظت شده است.

## تست‌ها و حفظ فایل‌ها

`npm test`: تمام تست‌های اصلی را اجرا می‌کند. `tests/faq-v14.test.js` تست‌های تازه FAQ را اضافه می‌کند. تست HTTP صفحه‌ها و مسیرهای مدیر به‌صورت جدا اجرا شد.

لندینگ جدید در `public/landing/` است. فایل `public/index.html` اصلی v1.3 **همچنان همان سازنده قبلی است** و برای حفظ تست‌ها دست‌نخورده از نظر ساختار و کارکرد باقی مانده است (فقط لینک FAQ مدیر اضافه شده است). فقط `server.js` آدرس `/` را به لندینگ جدید و `/builder` را به سازنده اصلی متصل می‌کند.
